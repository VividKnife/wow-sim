# 40人团本：三档装备与三套阵容挑战

2026-09-29。实际执行18次独立战斗：3档真实装备 × 3种40人阵容 × 2名首领。固定随机种子60325，无人数缩放，不添加世界增益、附魔或消耗品。每次从完整生命和法力开始。

## 配装与复现

- 五人本毕业：从最低等级45及以上五人地下城的真实精良掉落池按现有整套装备评分选取；排除随机属性和专业需求。这是明确可复现的毕业档测试配装，不声称逐职业最优BiS。
- 半身史诗：替换已占装备槽的一半，向下取整；本次每人8件史诗。保留蓝色武器组合。
- 全身史诗：所有已占装备槽使用熔火之心/奥妮克希亚真实史诗掉落，包含MC小怪掉落；依职业与双手武器为16或17件。
- 统一使用普通NPC策略；法师团长、战士坦克，牧师/圣骑士治疗，输出来自原演示职业池。没有对全部九职业和所有战术进行穷举。
- 配装遵守职业、双手/副手、唯一装备限制。逐人属性与装备ID保存在[原始结果](classic-40-raid-challenges.json)。
- 每组只跑一个种子，表中是具体案例，不能解读为胜率。

```sh
node scripts/benchmark-classic-raids.mjs --bosses=lucifron,ragnaros --output=docs/research/classic-40-raid-challenges.json
```

## 结果解读

- 五人本毕业 / 鲁西弗隆：3套阵容均失败；最低剩余生命24.99%（2坦 / 6疗 / 32输出）。
- 五人本毕业 / 拉格纳罗斯：3套阵容均失败；最低剩余生命39.39%（3坦 / 8疗 / 29输出）。
- 半身史诗 / 鲁西弗隆：1套测试阵容击败；最快为2坦 / 6疗 / 32输出，82.3秒，存活27人。
- 半身史诗 / 拉格纳罗斯：3套阵容均失败；最低剩余生命29.74%（2坦 / 6疗 / 32输出）。
- 全身史诗 / 鲁西弗隆：3套测试阵容击败；最快为2坦 / 6疗 / 32输出，70.2秒，存活24人。
- 全身史诗 / 拉格纳罗斯：3套阵容均失败；最低剩余生命30.74%（4坦 / 10疗 / 26输出）。

鲁西弗隆结果中存在较多未及时驱散的末日，治疗法力消耗很大。全紫并不保证所有首领通过；后续应检验驱散分工、站位、职业组合和资源策略，而非降低首领数值。

首领生命、近战、护甲和抗性来自[固定版ClassicDB](https://github.com/cmangos/classic-db/tree/22b51464f1625f6ef6275771de1f5466c6f5d19e)；法术效果由同一归档抽取。主要技能时序参考[固定版CMaNGOS脚本](https://github.com/cmangos/mangos-classic/tree/8ec338a1704e7dcb1c0213eb7ed58f9231ade40f/src/game/AI/ScriptDevAI/scripts/eastern_kingdoms)。这是社区可追溯参考，不是暴雪服务端源码。

已取消25/40生命削减，恢复加尔8随从、炎魔8烈焰之子和180/90秒阶段，并校正主要法术伤害、目标及独立冷却。15分钟仅是模拟预算，超时保留角色生命，不制造全团秒杀。

**仍未完成全部原版机制复刻。** 当前场地几何、移动、奥妮克希亚飞行/深呼吸路径仍是模拟；部分次要技能、可打断施法、烈焰之子法力燃烧与控制行为仍存在简化。本报告衡量当前模拟器，不能直接预测原版游戏通关。
