## 可复现来源

执行 `python docs/research/import/import-professions.py`。脚本使用 Python 标准库，下载后验证哈希，解析 SQL，不执行 SQL；每次生成均重新读取已验证的原始压缩库。

- [CMaNGOS ClassicDB](https://github.com/cmangos/classic-db/tree/22b51464f1625f6ef6275771de1f5466c6f5d19e)：原始 spell/item 模板、训练师、配方物品、商人、任务、掉落、分解表、简体中文物品名称。
- [经典客户端 DBC 镜像](https://github.com/soyalu/cmangos-classic-map/tree/93b11b73ee4e483ce414f3d5f99a9047d23a9e48/dbc)：SkillLineAbility 与 SpellItemEnchantment。该镜像为社区来源，不宣称已验证暴雪客户端构建签名。
- SQL SHA256：`4f92db520868ab4e566726f68b5b2e380ae781209beaf22237b4f7f04600d0c0`。
- DBC 与中文源的 SHA256 保存在生成文件 `meta` 和导入脚本中。

输出分为 `apps/web/data/professions-reference.json`（配方／成长／专精／附魔／中文名）和 `professions-templates.json`（压缩列式物品、法术模板）。目录只向运行时补齐缺失的模板，不导入世界刷怪与地图数据。

所有配方按技能法术 ID 去重。识别训练师教学法术、配方物品教学法术、任务、初始技能；对脚本教授的熔炼、工程传送器及特殊专业内容补充显式来源。排除的 34 条原始配方及原因保存在 `meta.excluded`。纳克萨玛斯冰抗套装、疯狂之缘、黑铁／源质熔炼、厄运之槌配方等特殊来源单独标注。

## 便捷规则与边界

- 全部生活职业均可学习，达到熟练度即自动解锁配方；原始来源作为目录说明，暂不要求前往未开发地图购买配方或完成声望／任务。
- 固定价格远程拍卖行供应目录材料与工具；补购、消耗、成品入包、费用与制造冷却在一个事务内完成，任何错误均回滚。工具不消耗，较高级符文棒可代替低级符文棒。
- 需要固定设施的配方在城镇工坊制造；不新增月亮井、黑铁熔炉等地图地点。转化使用原始共享冷却，月布等使用独立冷却；冷却配方禁止批量制造。
- 专精初选免费，重选 5 金；重选后旧专精配方重新受限制。该重选费用是模拟规则。
- 附魔改为可交易羊皮纸，价格依据材料成本。装备槽位、武器类型和双手要求会验证。锁定物品不允许修改。
- 一键分解保护史诗装备；单件操作可分解史诗装备。产物按原始分解表抽取，背包不足进入待拾取。原有剥皮继续使用分级皮革简化规则。
- 配方完整不等于全部成品战斗特效完整。基础属性、生命／法力、护甲、法伤／治疗、武器伤害、闪避、回蓝与威胁附魔已接入；命中触发、部分抗性／移动／采集技能等特殊附魔与工程装置特效仍保留为后续战斗能力，界面提示待接入。绷带沿用脱战即时恢复与 60 秒间隔的简化使用方式。
- 角色升级、各职业技能与地图开发由各自模块负责，本次仅扩充生活职业。
