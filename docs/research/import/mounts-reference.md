## 改编及限制

- 坐骑直接保存在角色收藏 `mounts`，不占背包、不交易；骑术保存在 `riding.horse`，活动坐骑是 `mounted`。沿用 JSON 存档，旧档默认空收藏与未学骑术。
- 原种族限制保留：人类可学习；矮人、暗夜精灵、侏儒需暴风城崇拜；部落不能学习马匹骑术。当前仅实现地图可用的马匹服务，未添加其他种族坐骑或职业坐骑任务。
- 沿用现有存档的声望点，9000 为尊敬折扣门槛（九折），42000 为崇拜门槛。不新增种族初始声望或 PvP 军衔折扣系统。
- 地图粒度有限：矿洞、法师塔、蓝色隐士和死亡矿井入口的整段进出按步行处理。这是路线近似，不声称精确的室内边界测量。
- 地铁固定耗时，不乘坐骑速度；进入受限段后，余程步行，不自动免费重新上马。飞行时下马，航程保持不变。
- 主动狩猎、施法、使用物品、采集、休息、护送、进入副本会自动下马，是本作自动活动的交互约定。战斗和死亡清除骑乘状态；上马受伤则中断。
- 已开始的旅行不允许中途切换坐骑，路径与每段耗时序列化；下马边界作为独立模拟事件，分次和一次离线结算结果相同。
