## 改编及限制

- 坐骑是普通背包物品：商人购买、管理员礼包邮件和测试直升均发放物品；使用后消耗一件并加入角色收藏 `mounts`，同时学会 `riding.horse`。已收藏的坐骑不能重复学习，不消耗重复物品。职业坐骑仍通过职业法术学习。
- 所有种族均可使用骑术训练师、马匹商人和坐骑，无阵营或声望门槛；暴风城声望折扣仍保留。
- 沿用现有存档的声望点，9000 为尊敬折扣门槛（九折），42000 为崇拜门槛。不新增种族初始声望或 PvP 军衔折扣系统。
- 地图粒度有限：矿洞、法师塔、蓝色隐士和死亡矿井入口的整段进出按步行处理。这是路线近似，不声称精确的室内边界测量。
- 地铁固定耗时，不乘坐骑速度；进入受限段后，余程步行，不自动免费重新上马。飞行时下马，航程保持不变。
- 主动狩猎、施法、使用物品、采集、休息、护送、进入副本会自动下马，是本作自动活动的交互约定。战斗和死亡清除骑乘状态；上马受伤则中断。
- 已开始的旅行不允许中途切换坐骑，路径与每段耗时序列化；下马边界作为独立模拟事件，分次和一次离线结算结果相同。

## 幽灵虎与管理员奖品

幽灵虎物品 ID 为 49283，使用后加入收藏，20 级可骑乘，移动速度 +60%。未满 20 级可以领取并学习，但不能召唤。管理员奖品页的坐骑快捷选项及名称搜索均复用普通物品附件，遵循背包容量、邮件领取事务与请求去重规则。

主页使用 display ID 21973。Classic 资源库缺少该模型，因此模型代理将其固定的元数据、M2、蒙皮、动画和纹理资源映射到同一官方 CDN 的 live 资源库；不开放任意上游地址。普通角色与其他坐骑继续使用 Classic 资源。

## Boss 掉落坐骑验收

目前导入的生物掉落表（含递归引用表）只有一件坐骑：斯坦索姆亡灵区瑞文戴尔男爵（10440）的死亡军马的缰绳（13335）。保留本地源表的 1% 掉率；这不是对不同历史版本官方掉率的断言。祖尔格拉布虎／迅猛龙和安其拉坦克物品尚未导入，未虚构其掉落。

死亡军马使用后消耗物品、加入收藏并学习骑术；保留史诗坐骑 60 级、移速 +100% 规则。多人或 NPC 队伍复用史诗物品 Roll：未收藏玩家可需求，已收藏玩家可贪婪或放弃，NPC 自动放弃。获胜后进入玩家待拾取列表；背包满时保留，清出空间后可重新拾取。

`packages/game-domain/test/boss-mounts.test.ts` 使用固定随机种子和实际男爵死亡结算验证掉落，不修改概率，也不声称模拟了一场完整 Boss 战。覆盖掉落表注册审计、满包重试、Roll、物品学习、等级限制、服务持久化／重启以及模型映射。主页的死亡军马使用 Classic display ID 10718，已在实际 WorldScene 预览中验证桌面和窄屏渲染。
