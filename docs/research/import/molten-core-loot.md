# 熔火之心掉落来源

掉落以经典旧世 1.12 为基准，不使用探索赛季、周年重制装备或自制装备。

- 数据库：CMaNGOS ClassicDB，提交 `22b51464f1625f6ef6275771de1f5466c6f5d19e`，源压缩包 SHA256 `4f92db520868ab4e566726f68b5b2e380ae781209beaf22237b4f7f04600d0c0`。
- `scripts/import-molten-core-loot.py` 可重复提取首领、小怪、炎魔宝箱 16719、引用掉落组、691 条物品和关联法术。原始列完整保留在 `packages/game-data/data/molten-core-loot.json`。
- 中文名称采用同提交中文本地化；装备说明和20套套装部件／效果使用 Wowhead Classic 中文 tooltip。每份 tooltip 记录 URL、SHA256，图标来自项目固定客户端纹理提交。
- 此版本 SQL 的负 `mincountOrRef` 表示引用，`maxcount` 表示重复次数，引用行的 `groupid` 选择目标组。多个 group=1 引用必须分别执行；不能误当作一个互斥组。

两种团本模式共用掉落器：T1 部件按原首领分配，腰带和护腕来自小怪；拉格纳罗斯包含 T2 腿和萨弗拉斯之眼；管理者使用宝箱掉落神圣之眼／远古石叶及装备；加尔与迦顿分别掉落两半逐风者禁锢之颅。萨弗拉斯和雷霆之怒成品不是首领直接掉落。

所有概率采用上述社区数据库记录，不声称是暴雪公开的精确概率。保留本作25人遭遇、周领取资格和金团经济规则。联盟部落合作规则允许圣骑士、萨满掉落同时出现；负概率任务物品只在玩家需要时生成，未开放的任务不会无条件发奖。套装信息显示原始效果，具体特殊法术仍由当前共同战斗引擎的支持范围决定，本次不扩展职业任务链或全部套装触发机制。
