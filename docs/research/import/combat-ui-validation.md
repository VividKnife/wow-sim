## 当前交互

- 点击野外怪物自动打开独立战斗窗口，也可通过「进入战斗界面」查看当前或最近一场战斗。
- 横向位置对应模拟距离，纵向分行用于避免角色重叠；不是二维移动或碰撞模拟。
- 显示双方生命、施法读条、近战进度、技能原版图标与名称、伤害/治疗飘字、挥击和命中光效。

- 可返回世界、请求本场结束后停止、开启/关闭已有音效；尊重系统减少动态效果偏好。
