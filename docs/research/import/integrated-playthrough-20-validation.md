# 新角色整合流程验证（2026-09-16）

## 方法与范围

从 1 级新建人类法师，以普通游戏命令执行任务、移动、战斗、训练、购买、装备和复活，模拟推进时间，不赠送等级、金钱、装备、技能或治疗。每段保留冻结的代码与数据、输入存档、命令记录、输出存档及回放校验。

这验证的是目前北郡—艾尔文—西部荒野—死亡矿井的共享路线，不证明所有种族出生地图、全部职业任务和原版数值已经完整实现。各段代码快照独立；后续修复不能倒推为已在该历史快照验证。

## 本轮修正与浏览器验证

- 招募保留出生熟练度，发放装备必须符合职业与熟练度；牧师初始备用武器改为可用单手锤。
- 自动验收脚本只选择实际可达的服务地点；传送专用服务地点不再误作步行目的地。
- 区域后续任务通过真实怪物掉落取得任务启动物；购买清凉泉水前实际前往有商店的闪金镇。
- 299 件本路线物品补充中文名与 188 个原版图标文件；未改动战斗数值。
- 无耐久度物品不再显示“已损坏”。浏览器中磨损的披风验证通过。
- 装备详情显示护甲类型和不可装备原因。真实新角色法师的狼皮护腕显示皮甲、装备按钮禁用；磨损的披风成功装备，护甲由 45 增至 50。
- 按用户要求删除读档时为旧角色补字段、补技能的迁移逻辑及专用版本标记，相关测试改为当前新存档创建与往返读取。已有测试角色本来就是本轮新建，无须再次清空。

失败的脚本尝试也保留：首个练级段在不可达服务节点选择处停止；区域收尾首次在无商店地点购买饮水而停止。修复后从实际存档继续，未伪造成功结果。
