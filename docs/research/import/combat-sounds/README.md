## 播放行为

- 默认关闭，由玩家点击启用。按钮点击声仅用于开关反馈，战斗不再回退到按钮声。
- 英勇打击、邪恶攻击、次级治疗、治疗术、快速治疗、恢复和魔爆术有明确映射；其他适用法术按实际学派使用通用原版音效。
- 普通近战使用通用原版挥击声；尚未按武器类型和目标护甲材质区分。这是呈现改编，不是完整客户端的逐技能/逐材质声音映射。
- 持续伤害不逐跳重复命中声；恢复不每跳播放；奥术飞弹保留每次飞弹命中的声音。
- 最多同时 4 个声音，同一种声音 180 毫秒内去重，优先当前角色；不排队播放过期事件。
- 资源在 600 毫秒内未开始播放便取消，防止弱网加载后迟到补播。播放开始、失败、结束、静音、关闭战斗页和离开页面都清理相应音频/定时器。
- 隐藏页面时停止播放；后台与重新打开前的历史日志不补播。
- 声音只订阅展示事件，不调用或改变模拟、随机数、技能释放或伤害计算。

- 音频映射、周期伤害、并发上限、重复抑制、停止、浏览器拒绝播放、慢下载取消：自动测试通过。
- 15 个文件 OGG 结构、哈希、原始网页文件 ID/URL 和 Vanilla 路径清单：自动验证通过。
