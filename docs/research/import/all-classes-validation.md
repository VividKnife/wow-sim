# 九职业、种族与成长系统验收

验证日期：2026-09-16。范围是当前 1—20 级二维冒险，不是完整 1—60 级旧世复刻。

## 已接入的玩法

- 九职业、八种族、40 个合法创建组合；等级属性、初始装备/技能、法力/怒气/能量和种族特性进入实际角色与战斗状态。
- 按职业训练技能：等级、训练师位置、费用、前一等级、职业归属及实现状态均由引擎校验。
- 27 棵天赋树；每棵树都能在 20 级分配完整 11 点已实现天赋。投入点数、层级、前置节点、最高等级和洗点费用均有校验。
- 职业机制包括怒气技能、圣印/审判、猎人与术士宠物、潜行伏击、治疗/护盾/持续治疗、图腾、德鲁伊形态及能量技能。宠物具有独立生命、受伤/死亡、伤害统计；死亡猎人宠物必须使用复活宠物，消耗法力并读条后恢复 15% 生命。
- 技能与天赋的已实现范围由 `class-support.js` 的集合声明。当前训练目录共有 190 个可执行技能等级条目、121 个可投入天赋节点。未实现参考条目明确禁用，不能扣除金币或天赋点。
- 技能/天赋中文名与已实现条目的真实图标已接入；118 个补充图标具有来源、哈希和可重跑导入脚本。

## 改编边界

- 所有种族共用北郡到死亡矿井路线。导入任务中仅面向整个阵营、且没有职业限制的种族掩码 77/178 任务可跨阵营接取；职业专属与单一种族限制仍保留。
- 尚无完整原版职业任务线；必要的宠物、形态、图腾和复活能力在训练师以“职业解锁（共用路线）”免费提供。
- 宠物种类/数值、图腾和形态使用当前二维模拟；未包含宠物快乐值、完整宠物训练、全部种族技能和所有参考天赋效果。非人类角色没有套用人类三维模型。

## 回归与浏览器验证

- 全仓 `npm test`：341 项中 340 项通过。唯一失败为同时开发中的 `classic-professions.test.mjs` 导入不存在的 `professionRanks`；本轮未修改该接口。
- 九职业数据/成长/战斗/持续恢复/共用任务路线专项：42/42 通过。旧存档、恢复和会话等其余测试包含在全仓已通过结果中。
- `npm run check`、Web `npx tsc --noEmit`、Web `npm run build`、`git diff --check` 通过。
- 九职业训练后的战斗支持 JSON 存档续跑及分段推进，结果一致。
- 浏览器真实引擎夹具 `apps/web/test/browser/classes.html`：核对合法种族下拉、当前职业资源与身份；萨满加点后可用点从 11 变为 10，洗点恢复 11 且费用升至 5 金；猎人学习一级毒蛇钉刺后解锁二级训练；职业解锁宠物后参与实际战斗，独立伤害统计为 19 点、45.2%。已实现技能图标正常加载。
- 独立代码复核发现并修复：猎人面对高速近战怪无限后退、部落起始任务缺失、潜行被自动攻击打破、持续治疗在下一战斗补发过期治疗、二级力量图腾沿用一级属性。复核确认这五项均已解决。
