# 自然成长中牧师战斗停滞修复

日期：2026-09-16。

## 复现与根因

自然命令验收运行 `.cache/refactor-journey-priest/final-state.json` 停在3级，对狗头人劳工257的战斗持续600秒后，怪物剩8血，玩家剩72血、0法力、22次击杀。日志重复次级治疗术：实际恢复13–14、过量33–40。

并非怪物生命或伤害配置错误。战斗分发将主控牧师也交给队友牧师救急策略：85%生命即治疗，覆盖主控默认55%规则；救急还会取消正在施放的惩击。伤害分支要求保留70%法力，并且所有牧师被禁止普通近战。因此低蓝主控不停用刚恢复的法力过量治疗，无法打掉最后8血。

新增 `apps/web/test/priest-player-combat.test.mjs`，先观察4项全部失败：70%生命绕过用户阈值、惩击被取消、禁用规则仍施法、无蓝20秒零伤害。

## 最小修复

- `companion-combat.js`：主控角色不使用队友独立救急、自动防御及85%自动治疗。主控惩击按配置规则和真实可支付法力施放；仍检查沉默、学校锁定、冷却与策略条件。队友继续保留原救急与70%保蓝行为。
- `combat.js`：主控牧师没有读条时允许普通武器攻击，队友牧师保留后排行为。
- 未修改怪物、伤害、费用、再生及默认治疗阈值。

## 验证

```text
node --test apps/web/test/priest-player-combat.test.mjs apps/web/test/party-combat.test.mjs apps/web/test/party.test.mjs apps/web/test/class-combat.test.mjs
48/48（新增回归当时为4项）

node --test apps/web/test/priest-player-combat.test.mjs
5/5（补充最后一发法力足够的惩击，以及低于55%仍正常治疗）
```

原失败checkpoint无任何修改，直接调用当前 `advance` 续推20,000ms：击杀22→23，战斗结束；生命保持72，法力恢复到152。新增三个主控武器伤害事件为2、4、2，总计8，原剩余生命被正常扣完。

这证明具体战斗阻断已解除，不等于牧师1–20自然成长已全部通过。主验收随后从1级重新运行并独立记录最终结果。
