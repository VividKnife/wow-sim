# 九职业战斗界面

本次在现有自动战斗模式上接入职业状态和操作入口。界面读取实际战斗状态，不按等级虚构技能、资源或效果；适用于现有 1—60 级角色。

| 职业 | 战斗界面 |
| --- | --- |
| 战士 | 怒气、当前姿态、血性狂怒、天赋触发、主副手攻击计时 |
| 圣骑士 | 法力、圣印、光环、目标审判、奉献范围、治疗和护盾 |
| 猎人 | 法力、自动射击距离与计时、守护、宠物生命与集中值、快乐和忠诚度、宠物指令 |
| 潜行者 | 能量及天赋上限、潜行、绑定目标的五点连击显示、主副手毒药和冷却 |
| 牧师 | 法力、治疗与引导目标、吸收盾、虚弱灵魂、暗影形态、受控目标归属 |
| 萨满祭司 | 法力、四元素图腾的生命和寿命、护盾充能、武器强化 |
| 法师 | 法力、护甲和护盾、施法与引导、控场、天赋触发和冷却 |
| 术士 | 法力、灵魂碎片、目标持续伤害、恶魔生命与法力、恶魔指令 |
| 德鲁伊 | 当前形态；熊怒气、猎豹能量及目标连击点；动物形态保留法力条；持续治疗 |

共同功能：九职业各自的图标；选择任意战斗单位后查看其资源、效果、冷却和控制状态；职业战斗策略可在战斗窗口内编辑保存。策略的主要资源条件实际读取怒气、能量或法力。猎人自动射击与副手使用引擎自身的时间戳。

宠物指令包括被动、防御、主动、跟随、停留及攻击选中敌人，通过既有动作接口执行。角色或宠物死亡、战斗结束后禁用。图腾没有可移动或可挥击的假状态。宠物和图腾使用对应素材，不再裁切职业头像。

战斗结束后，生命、职业资源、形态、宠物、图腾、种族效果和天赋状态从结束快照读取；后续恢复和时钟推进不会覆盖回看。冷却和效果倒计时同样停留在结束时刻。

- 审查收尾后的职业投影、React 服务端组件渲染、战斗显示和快照专项：38 项通过。
- 覆盖九职业资源、独立头像、德鲁伊双资源、目标连击点、实际宠物命令、四元素图腾、种族和天赋状态、审判和奉献、结束快照及禁用控制。
- `npx tsc --noEmit`、JavaScript 语法检查及生产构建。
- 此轮未执行浏览器视觉验收，也未发布站点。
