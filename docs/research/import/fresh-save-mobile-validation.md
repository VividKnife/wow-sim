## 稳定预览

并行数据改写曾触发反复热更新并导致预览工作进程内存耗尽。默认文件监听增加写入完成等待；连续验收可在 `apps/web` 中启动：

```powershell
$env:WOW_SIM_STABLE_PREVIEW='1'
node scripts/run-framework.mjs dev --port 5173
```

此模式关闭文件监听，后续源代码改动需要重启服务。默认开发模式仍启用监听。
