# 拍卖商品阶段（2019 Classic）

当前 `market-content-phases.json.currentPhase = 1`。这是全服内容阶段，与角色等级、团本战斗阶段无关；BIS 和拍卖行共用这个值。修改阶段需重新生成内容清单，不接受客户端购买命令传入阶段。

## 数据与校正

- [暴雪：物品属性与开放阶段](https://us.forums.blizzard.com/en/wow/t/itemization-in-wow-classic/160757)：1.12 属性不意味着全部物品在首发可获取。
- [ClassicDB 泰坦护腿](https://classicdb.ch/?item=22385)：P5。从该库的分类列表提取候选商品及专业配方的后续阶段，保存查询 URL、响应 SHA-256、行数和提取后的 ID → 阶段；每个查询不足 500 行，避免截断。
- [2020 年 P3 声望配方公告整理](https://www.wowhead.com/news/new-reputation-items-available-when-wow-classic-phase-3-blackwing-lair-opens-311074)：瑟银兄弟会、木喉和银色黎明后续配方。
- [专业成品阶段索引](https://www.wowhead.com/classic/guide/classic-endgame-crafting-recipes)及 [P5 专业更新](https://www.wowhead.com/classic/guide/professions/professions-recipes-quests-phase-5)：交叉核对成品、专属材料、附魔。后者更新于周年服时期，仅采用与 2019 记录吻合的条目，不整体套用周年服规则。

资料不是无冲突的官方逐物品清单，显式校正组优先于数据库值：

- 厄运之槌：旧表有 P2 标记，但[暴雪实际于 2019-10-15 开放](https://eu.forums.blizzard.com/en/wow/t/dire-maul-releases-at-7-00pm-cest/95653)，早于 P2。因此本项目的 P1 范围包含该次开放，大法师腰带、野性之皮等保留 P1，不将“首日”和“整个 P1”混用。
- 灵魂袋、鼠尾鱼配方：不采用数据库中的 P5 旧标记。参考 [2019-10-01 玩家对灵魂袋的同期记录](https://us.forums.blizzard.com/en/wow/t/soul-bags/318626)和 [2019-10-02 钓鱼记录](https://blizzardwatch.com/2019/10/02/make-gold-fishing-wow-classic/)。
- 希利苏斯沙行者/飞火组按 P4 内容组处理，配方跟随成品阶段；与旧数据库 P5 标记的冲突保留在原始映射中。
- 未单列的基础物品默认 P1。节日实际日期、服务器开门进度未模拟；不能将这张表称为全部历史可获取日期的认证。

## 执行边界

`content-phase.js` 解析阶段元数据，配方文档跟随成品阶段，附魔羊皮纸按对应附魔阶段限制。它不会把晚期转化配方的阶段反向传播给已有早期来源的材料（例如元素火焰）。

- 内容包仅发布当前阶段的拍卖商品。
- `reserveMarket` 在扣钱和预留任何库存前拒绝后续阶段商品，因此直接购买和专业自动补购都不能绕过。
- 后续阶段物品不能上架收购，背包的可交易状态也会反映此限制。
- 补货只改变已开放商品库存，不解锁阶段。
- 本次阶段约束针对拍卖交易；世界掉落、专业学习和制造本身不是本次全局阶段审计的范围。

UI 左侧分类、子分类、护甲部位来自实际商品元数据，显示当前路径。普通列表只显示库存；选中缺货商品时才显示预计补足时间。
