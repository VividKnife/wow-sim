# 副本连续推进

点击「开始自动推进」后持续推进当前路线，包括首领、可选遭遇与机关；不会自动跳过支路。当前场景仍保留三秒开怪倒计时、原有战斗数值、掉落、机关物品和时间消耗。

- 首次点击仍立即进入当前遭遇。后续遭遇前使用现有恢复阈值与食水规则休整，不快进，也不免费回满。
- 自动拾取由服务端规则引擎在战后、下一场推进前执行，不依赖战利品窗口或页面可见性。关闭自动拾取时有待拾取物品就暂停；背包放不下的掉落始终保留。
- 牧师存活时，战后自动逐个复活阵亡成员（包括队长），再按恢复设置休整并继续。使用已学复活术的实际读条、法力消耗和冷却；法力不足时先使用现有补给或自然恢复，达到复活所需法力后施法。最后一场结束也会完成复活。
- 没有存活牧师或全队阵亡时暂停，绝不自动跑尸。牧师未学复活术或法力上限不足时显示具体阻挡原因。背包已满、待拾取物品、队伍人数不足、通道未打开或缺少火药时仍暂停。
- 解决导致暂停的阻挡后点击「继续自动推进」。手动复活、清理背包不会重新开启已经暂停的自动推进。
- 「暂停推进」不取消当前战斗、已开始的复活读条或已点燃的火炮；完成当前动作后不再自动复活其他成员或开怪。离开副本也会停止推进，重返时保留路线。

推进状态保存在副本实例中，由规则引擎和服务 worker 执行，刷新和服务重启不会丢失。离线推进仍受现有参与者离线时限约束，未调整离线政策。

验证：`apps/web/test/dungeon-auto-advance.test.mjs` 覆盖真实连续战斗与拾取等待，以及受控死亡、满包、恢复、机关、暂停、完成和分段结算；`packages/game-domain/test/dungeon-progress.test.ts` 覆盖 worker 跨服务重启继续推进和战斗中暂停。受控胜利夹具用于流程验证，不代表完整副本平衡验收。
