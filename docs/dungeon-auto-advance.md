# 副本连续推进

副本地图显示死亡矿井与暴风城监狱的全部遭遇、支路、首领、机关和小队位置。底图使用暴雪客户端原版地图纹理：死亡矿井分为矿道与船坞两张，监狱为一张，支持完整显示、分区切换和小队定位。图标为房间级锚点，战斗仍使用原始出生位置与场景。点击「全清副本」后持续清理剩余区域，包括首领、可选遭遇与机关。当前场景仍保留三秒开怪倒计时、原有战斗数值、掉落、机关物品和时间消耗。

- 点击地图首领可查看其掉落、相关任务和路线预览，再点击「推进并击杀该首领」。普通怪物群也可作为目的地。沿连接路线清理敌人，完成目标遭遇后停止，不会继续迎战其他区域。
- 死亡矿井主线保留前置首领、斯尼德两阶段与火药/火炮机关；约翰森、船坞侧道、曲奇与出口为支路。监狱支持分别前往中央通道、东翼、西翼首领。
- 战斗中调整目的地会保留当前战斗，胜利后按新路线前进。也可点击「本场结束后停止」，待战斗结束再决定目的地。已点燃的火炮同样先完成机关再改道。
- 指定目的地模式不会把未走的支路标记为已清理；之后选择全清会补完剩余区域，包含之前主动绕过但仍有敌人的可选遭遇。已击败的敌人不会重生或重复发奖。本次未刷新的稀有首领不能选为目的地，但仍可查阅掉落。
- 黄色任务标记来自当前已接受且未完成的击杀目标、掉落任务物品目标；任务完成或相关怪物被击败后更新。斯尼德第二阶段目标也标记在伐木机房间。

- 原有推进/继续按钮立即进入当前遭遇。地图出发与后续遭遇使用现有恢复阈值与食水规则休整，不快进，也不免费回满。
- 自动拾取由服务端规则引擎在战后、下一场推进前执行，不依赖战利品窗口或页面可见性。关闭自动拾取时有待拾取物品就暂停；背包放不下的掉落始终保留。
- 牧师存活时，战后自动逐个复活阵亡成员（包括队长），再按恢复设置休整并继续。使用已学复活术的实际读条、法力消耗和冷却；法力不足时先使用现有补给或自然恢复，达到复活所需法力后施法。最后一场结束也会完成复活。
- 没有存活牧师或全队阵亡时暂停，绝不自动跑尸。牧师未学复活术或法力上限不足时显示具体阻挡原因。背包已满、待拾取物品、队伍人数不足、通道未打开或缺少火药时仍暂停。
- 解决导致暂停的阻挡后点击继续推进，保留当前目的地。手动复活、清理背包不会重新开启已经暂停的自动推进。目的地已完成时需另选目标或全清。
- 「暂停推进」不取消当前战斗、已开始的复活读条或已点燃的火炮；完成当前动作后不再自动复活其他成员或开怪。离开副本也会停止推进，重返时保留路线。

推进状态保存在副本实例中，由规则引擎和服务 worker 执行，刷新和服务重启不会丢失。离线推进仍受现有参与者离线时限约束，未调整离线政策。

验证：`apps/web/test/dungeon-auto-advance.test.mjs` 覆盖真实连续战斗与拾取等待，以及受控死亡、满包、恢复、机关、暂停、完成和分段结算；`packages/game-domain/test/dungeon-progress.test.ts` 覆盖 worker 跨服务重启继续推进和战斗中暂停。受控胜利夹具用于流程验证，不代表完整副本平衡验收。

地图回归：`apps/web/test/dungeon-navigation.test.mjs` 覆盖拓扑完整性、指定首领停止、跨翼改道、暂停后改道、全清补刷、机关/阶段前置、任务标记、无效目标与拾取后继续。浏览器夹具：`node apps/web/scripts/serve-dungeon-preview.mjs`，打开 `/dungeon.html` 的「矿井地图」「监狱冒险」。
