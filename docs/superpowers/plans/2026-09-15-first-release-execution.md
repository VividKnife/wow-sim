# 首版完整实施与验收

用户已授权直接开发、自主测试并持续推进至完成。目标延续已确认的人类法师 1—20 级路线，扩展为北郡、艾尔文森林、西部荒野、必要城市服务与死亡矿井的全部入选任务内容。不得以只有存档页面或数值基础代替完整首版。

## 实施顺序

1. 固定来源的数据、图标、中文名称和转换脚本。
2. 角色创建、账户隔离存档、幂等操作和服务器时间。
3. 角色成长、技能训练、天赋、装备、背包、补给、商店和修理。
4. 地点旅行、任务领取/目标/奖励、优先级自动战斗、离线结算。
5. 持久 AI 队友、五人组队、死亡矿井每组遭遇和首领机制。
6. 完整正常倍率 1—20 级旅程和死亡矿井通关测试，补齐不可完成任务与所有发现的问题。
7. 手机浏览器操作、刷新/重连/后台暂停、构建与私有发布。

## 新增界面参考（用户于 2026-09-15 提供）

用户提供了两张手机游戏照片，允许参考或改善。采用其信息结构：

- 世界/区域地图选择目的地，显示连接、等级范围、当前位置和任务标记。
- 地点内以原版图标网格展示 NPC、怪物、资源与交互对象；提供类别筛选。
- 任务、队伍和状态靠近当前地点内容；活动状态和停止入口始终可见。
- 改善窄屏可读性：至少 44px 触控目标，名称正常换行，详细数值按需展开。
- 不照搬参考图的虚构地名、版本号或内容；采用已选经典数据里的实体。
