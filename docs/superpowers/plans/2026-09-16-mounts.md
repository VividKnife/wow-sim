# 坐骑系统实施计划

目标：落实首版已确认设计中的坐骑资格、费用、速度与限制，并提供世界页入口。
依据：`docs/superpowers/specs/2026-09-15-wow-sim-first-playable-design.md` 第 20、71 行。

在现有工作区增量实现，保留其他正在进行的修改。正式角色仍为 1—20 级；按用户最新要求，普通坐骑与骑术 20 级解锁，60 级迅捷马流程使用独立测试角色。沿用 Sites 页面、JSON 存档与纯函数引擎，不修改数据库模式。

- [x] 为训练、购买、读条取消/恢复、非法操作、旅行与旧存档编写行为测试，并确认缺失功能导致失败。
- [x] 新增 `lib/game/mounts.js`：马匹目录、骑术与收藏状态、资格/价格、读条及下马、派生界面数据。接入现有东谷训练师/商人。参考数值及覆写依据记录于研究文档。
- [x] 扩展 `catalog.js` 路线的骑乘模式：户外按坐骑速度，限制路段下马，之后步行；固定交通时间保持原值。路径保存每段耗时和骑乘状态，使地图、导航、离线结算一致。
- [x] 接入 `engine.js`、`navigation.js`、战斗与副本入口：新旧存档初始化、动作验证、自动下马、骑乘进度。
- [x] 新增 `app/mounts.tsx` 与响应式样式，在世界页加入收藏、训练、购买、骑乘与下马入口；通用活动进度支持 3 秒上马。
- [x] 运行坐骑/导航/旧存档回归、完整测试及站点构建，记录结果。既有站点修改不自动部署。

验收：低等级不越权；重复购买不扣款；20 级获得普通马并提升户外速度；60 级迅捷马更快且不重复收取骑术；战斗、死亡、变形、护送、副本与室内禁止上马；飞行和地铁不加速；读条可取消，恢复无重复奖励；界面禁用原因与服务端一致。

验证（2026-09-16）：坐骑专项 12/12；全项目 320/320；TypeScript --noEmit 通过；生产构建通过。Sites 构建包装脚本遇到本机 npm 路径错误，使用既有 `node scripts/run-framework.mjs build` 完成同一生产构建。独立只读代码审查无发现。没有发布线上版本，没有修改真实角色存档。
