# 暴风城监狱与地下城手册

用户已确认完整副本及关联任务链，并要求地下城 tab 提供所有地下城、首领与掉落浏览。版本沿用 2019 Classic / 1.12 参考基准。

## 内容与运行

暴风城监狱包含五名固定首领、一名稀有首领、普通怪组、战斗技能、任务掉落和装备掉落。复用确定性战斗、五人队伍、自动推进、恢复和服务器实例，不复制一套运行引擎。副本定义以 ID 注册；入口、等级、路线、稀有刷新和特殊事件属于定义，活动进度按副本 ID 保存。死亡矿井机关及斯尼德阶段仍作为该副本的特有机制。

任务覆盖监狱六项地下城任务及各自前置；死亡矿井未寄出的信衔接到监狱暴动，继续暴风城调查、袭击事件、最终乌瑞恩的图章。接交地点必须可达，事件必须真正推进并完成目标；失败可重试、不能重复结算。外部地图仅补任务必要节点与交通，不展开无关区域。

## 地下城手册

覆盖经典旧世地下城，以地下城卡片展示名称、区域、等级、状态；支持搜索。点开显示介绍、首领选择、掉落物品及基本属性。副本资料浏览与可进入状态独立；仅已实现的死亡矿井和监狱允许启动实例。团本不混入五人地下城。掉落来源优先采用已固定 Classic-DB 归档；资料记录与实际可玩能力分别标记。

服务端通过静态 clientContent 返回 journal 列表，通过实时 view 返回可玩副本视图，客户端不导入规则层。条目包含 id/name/zone/minimumLevel/recommendedLevel/description/playable/bosses；boss 包含 id/name/rare/description/loot；loot 使用物品展示对象并携带 source/chance 信息。手机上总览和详情分步浏览；当前冒险保持可见，不因资料选择而变更正在进行的副本。
