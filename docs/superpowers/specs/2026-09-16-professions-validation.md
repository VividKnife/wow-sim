# 生活职业与经济验证

## 已实现
- 12 种生活职业，28 个配方，训练及熟练度进阶。
- 按地区地形分布的草药、矿脉与鱼群，自动连续采集，游戏时间刷新；野兽击杀自动剥皮，溢出保留待拾取。
- 配方一键补齐、补齐并制造；原子扣费与材料消耗，锁定材料不消耗。
- 背包堆叠整理、灰色垃圾出售、物品锁定、绿色/蓝色装备批量分解、大背包替换小背包。
- 银行存取、拆分、整理、材料批量存入、扩容。
- 模拟拍卖行购买、自动定价上架、30 秒收购、5% 手续费、撤回、成交历史。
- 5 种附魔羊皮纸，制造与购买，适用装备槽位校验，附魔属性生效且不叠加。
- 成员药水阈值及选择，真实背包消耗、120 秒共享冷却。

只初始化新存档，依用户要求未添加旧档兼容或迁移。价格、采集分布、配方和技能进度均为本项目单人改编。
