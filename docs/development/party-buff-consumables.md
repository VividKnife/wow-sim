# 团队增益消耗品

副本与金团营地的「全团补 Buff」检查职业增益，以及达到物品等级要求的成员合剂、武器强化。

- 分为经济补给与强化补给：治疗为先知药剂 / 精炼智慧合剂，法系远程为强效奥法药剂 / 超级能量合剂，坦克为坚韧药剂 / 泰坦合剂，物理输出为猫鼬药剂 / 泰坦合剂。
- 近战、坦克和猎人检查符合物品武器类型要求的主副手强化。经济档使用致密磨刀石或致密平衡石，强化档使用元素磨刀石。野性德鲁伊不检查磨刀石；已有有效毒药或职业武器强化视为就绪，不自动覆盖。
- NPC 缺货时按性格给单件强化补给设定钱包占比上限：排骨攒金 0%、理性提升 3%、毕业收藏 8%、豪爽老板 20%、上头土豪 30%。强化档价格超过上限就选经济档；经济档仍买不起则提示金币不足。自备道具优先使用，不受采购预算限制；已有有效的任一档补给均视为就绪，不提前升级或降级。
- 优先消耗成员自己的未锁定道具。NPC 缺货时按 `marketPrice(itemId).buy` 从个人钱包直接扣除一件的价格并使用，不占用团长背包或金币，也不预购库存。
- 团长必须自备道具；缺货、武器锁定、NPC 金币不足会保留在成员缺项中，不归入团队无法提供的职业增益。
- 指令先执行职业施法，再逐件使用消耗品。施法次数与道具件数分别统计；费用与资格在实际使用时重新检查。已生效的增益不重复使用，过期后再次下令补充。
- 同一补给检查项的药剂 / 合剂不通过重复指令叠加，属性和持续时间来自物品法术记录；团队复活保留尚未过期的合剂，经济药剂死亡后移除。元素磨刀石每把武器增加 2% 暴击，致密磨刀石 / 平衡石为对应武器增加 8 点伤害，持续时间来自物品法术，效果绑定武器实例，换武器或过期后失效。

核心逻辑位于 `raid-consumables.js`，由 `party-buffs.js` 的只读检查和补充队列共用。相关行为测试为 `raid-consumables.test.ts`。
