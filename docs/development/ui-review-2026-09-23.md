# 游戏界面逐页检查与优化

日期：2026-09-23

## 玩法与设计依据

以当前运行时代码为准：旅行、接交任务、自动狩猎与恢复构成练级循环；通过装备、技能、天赋和优先级策略提升队伍，再进入五人副本、25 人团本和 NPC 对战。当前自有队友在 10 级解锁，冒险者大厅在 18 级解锁，二者入口需要区分。

视觉采用深色石板、旧铜边线和原有经典职业、角色、物品素材。页面标题说明当前位置或玩法；操作旁展示人数、资源、门槛和阻塞原因。删除无关风景、宣传式口号和重复说明，详细规则按需展开。没有改动阵营访问规则或游戏数值。

## 逐页处理

| 界面 | 发现的问题 | 本次处理 |
| --- | --- | --- |
| 全局导航与状态 | 蓝绿渐变、大圆角和反复出现的招募提示占据注意力 | 收敛为铜色选中态、紧凑资源条；招募提示仅留在世界页 |
| 世界 | 虚构山景与通用旅程文案挤走实际活动；筛选在人物后面 | 删除装饰横幅；展示真实地点、区域地图、任务数量与可交付数量；筛选移到附近活动前 |
| 地图与任务 | 地图展开状态不明确，任务日志入口在长列表底部 | 地图按钮提供展开状态与关联区域；顶部任务链接可直达日志，日志支持焦点定位 |
| 装备与背包 | 标题与八个导航按钮挤在一行；长属性表推迟背包操作 | 功能导航独立成行，手机固定四列；属性与抗性折叠查看，保留所有明细 |
| 法术书与天赋 | 训练提示只提及联盟地点；未分配天赋不够醒目 | 改为本职业训练师提示；天赋入口显示可用点数 |
| 策略 | 规则编辑前堆积长篇机制说明，模板标题固定写 20 级 | 保留优先级说明，把职业技巧与机制放入折叠区；模板标题改为职业推荐策略 |
| 坐骑 | 骑术门槛与收藏入口清楚 | 实际打开检查，保留现有流程 |
| 我的队友 | 入口默认进入 NPC 大厅；空席只占位，招募需要长距离滚动 | 默认展示自有队友；空席链接到招募区；压缩手机空席与阵容摘要 |
| 副本组队 | 叙事式标题重复，阵容与野外队伍容易混淆 | 标题明确为副本出征名单，保留独立名单说明 |
| 地下城 | 准备检查在长目录后；已开放副本一律标为可挑战 | 准备区前置；出征名单折叠；新增等级筛选，列表和详情均显示等级资格；入口操作移到掉落详情前 |
| 团队副本 | 公会团和金团同时展开，页面过长 | 两个模式分签展示；已有团本继续直接展示当前活动；金团以四步流程代替宣传标签 |
| PvP | “玩家对战”容易误认为真人匹配，外层与内层介绍重复 | 明确 NPC 对手；进入页面优先恢复已有竞技场；压缩模式切换与标题区 |
| 生活职业 | 制造规则与开发资料说明过长；错误状态同时显示空结果 | 制造规则折叠，去除过时开发说明；请求失败时不再显示“没有匹配的配方” |
| 银行与拍卖行 | 商品卡片使价格比较与浏览效率低 | 商品改为图标、物品名、价格与购买按钮并列的清单；补齐选择态语义，保留银行位置限制 |
| 战斗概览 | 无条件提示“离线继续”会误导副本玩家 | 区分副本战斗与野外狩猎状态 |
| 战报 | 时间、事件与战斗入口已清楚 | 检查空状态和现有记录逻辑，保留时间线 |
| 音乐 | 手机悬浮整条播放器遮住游戏内容 | 底栏提供音乐设置弹层；保留播放、暂停、音量、键盘和 Escape 关闭 |

## 验证

- 独立预览使用真实前端组件和内存角色；补齐当前内容分包与工坊接口，不访问玩家存档。
- 浏览器打开世界、角色八个子页面、队友、地下城、公会团、金团、战场、竞技场、战报；检查桌面和窄屏布局。
- 验证地图展开与收起、附近活动筛选、音乐弹层与键盘音量、招募后人数和职责更新、地下城等级筛选。
- 20 级测试角色从 28 座目录筛出 12 座等级符合的地下城；筛选后无等级不足卡片。
- 招募战士后，人数由 1/5 更新为 2/5，坦克由缺 1 位变为已就位。
- 生活职业加载 111 条炼金配方，分页 5 页；未学习的制造按钮保留禁用原因。
- 定向回归测试 43 项通过，包含 NPC 交互、属性、物品提示、队伍推荐、策略、战报和副本等级门槛。
- Web TypeScript 检查通过。默认 Node 堆曾不足，使用项目构建相同的 8 GB 堆完成检查。
- 游戏与预览源码未发现原生 select、option 或 NativeSelect。

本轮验证以界面、入口、反馈和状态表达为范围，没有完整重跑 60 级团本或竞技场战斗，也没有进行线上部署。
