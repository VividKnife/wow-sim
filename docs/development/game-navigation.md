# 游戏导航

主导航包含世界、角色、队伍、地下城和战报。

- 角色页包含装备与背包、法术书、天赋、策略、坐骑、生活职业、银行和拍卖行。顶部角色选择器统一决定天赋和策略的配置对象，切换角色时保留当前分栏。策略页不再提供第二个成员选择器；战斗面板仍可快速查看和调整成员策略。
- 世界页的旅行工具保留护送和采集。西部荒野和副本内提供地下城页的跳转入口。
- 地下城页在任何区域均可打开。进入前展示队伍人数、坦克和治疗职责、食水及倒下成员数量，提供队伍管理和角色配置入口。死亡矿井卡片使用现有地点、等级及活动限制；进入后展示遭遇、休整和完整路线。成功进入副本时自动切换至地下城页。

角色分栏由游戏页面持有，角色内容仍按角色 ID 重新挂载，避免切换成员后沿用前一角色的策略草稿。
