# 1—60 级 P1 内容

本阶段范围由用户确定：全部经典地下城（含厄运之槌），团本到熔火之心和奥妮克希亚。P1 表示本项目功能范围；数据源为 Classic 1.12，并未重建历史首发每个补丁的掉落版本。

## 已接入

- 世界 311 个地点、46 个区域标签。新增灼热峡谷、燃烧平原、诅咒之地、东西瘟疫之地、艾萨拉、费伍德森林、冬泉谷、安戈洛环形山、希利苏斯及道路、飞行点。种族出生地和六大主城保留；联盟、部落互不敌对。
- 28 条可进入的地下城分区路线。后半程新增祖尔法拉克、玛拉顿三分区、沉没的神庙、黑石深渊、黑石塔上下层、厄运三翼、通灵学院、斯坦索姆两翼。各自保存遭遇进度，NPC 招募与服务端入口覆盖全部地下城。黑石塔上层同其他地下城采用本作五人模式。
- 两个公会团本使用独立周进度、奖励资格和存档恢复。熔火之心 10 首领；奥妮克希亚含巢穴守卫、65% 升空、雏龙、火球、深呼吸预警与范围伤害、40% 落地、恐惧与熔岩。空中阶段禁止近战命中。团本采用核心五人加公会二十人的数值改编。
- 地下城及团本卡片背景、50 张本次导入的分层地图纹理、166 个首领肖像、45 张世界地图。模型资源清单共 2,855 项，物品图标映射 4,716 项；这些是资源条目数量，不能等同于不同怪物或装备数量。副本地图坐标、节点路径与楼层归属为本项目改编。
- 世界源包含 3,837 条任务、7,297 个生物模板、11,529 个物品模板，接入商人、任务端点、击杀目标、交付、前置、种族/职业条件和奖励。新增皇帝、黑暗院长的部分技能规则；团本击杀也可推进任务目标。

## 尚未完成的原版还原

此版本不能标记为“全部原版内容完成”。导入任务记录不等于逐条通关；护送、剧情、职业特殊事件仍有节点式改编。任务端点、目标动作和物品来源已按范围分类修复，后续阶段及未开放节日记录不对玩家开放。黑石深渊酒吧/竞技场、厄运贡品和加丁传送已有可执行的节点改编：竞技场采用两波固定预赛及随机冠军，加丁侧室采用可协作的战场侧翼。团本门任务已成为队长的入场条件，60 级远征预设预先满足。详见 [审计修复记录](world-audit-fixes-2026-09-23.md)。

源怪物分组形成节点路线，并非原版可自由行走的三维副本。多楼层地图根据源坐标和高度分配，尚未逐点人工验证。奥妮克希亚空中阶段已影响战斗，但模型尚无对应升空动作。部分源物品的外部图标资料不可用，保留通用显示回退。

## 来源与再生成

ClassicDB 固定提交 `22b51464f1625f6ef6275771de1f5466c6f5d19e`；SQL 文件与校验和见 [1—40 阶段记录](world-1-40.md)。首领脚本固定提交 `8ec338a1704e7dcb1c0213eb7ed58f9231ade40f`，文件及 SHA-256 见 `docs/research/import/classic-boss-scripts.json`。地图与卡片来源见 `docs/research/import/dungeon-presentation-manifest.json`。

世界定义在 `world-content.js` 与 `world-endgame.js`；使用 `import-world-content.py` 重建世界源数据、`import-world-localization.py` 更新中文、`import-dungeon-script-data.py` 更新脚本法术。地图与美术使用 `import-dungeon-presentation.py`、`import-dungeon-map-bounds.py`、`import-world-map-bounds.py`，Python 需要 Pillow。模型范围由 `export-world-model-scope.mjs` 导出。完成数据更新后运行 `npm run data:compile` 和 `npm run data:check`。

## 验证

`endgame-p1.test.ts` 覆盖全世界可达性、28 个分区地图、奥妮克希亚三阶段与序列化恢复、深呼吸真实伤害、周奖励幂等、服务端实例持久化，以及 25 人实际战斗通关。7 项通过。世界与美术覆盖检查 17 项通过，相关集成检查 37 项通过。熔火之心遭遇回归中迦顿调整为本作 240 秒狂暴后通过；这些测试证明本作行为，不认证原版数值。

TypeScript、内容清单校验及生产构建通过。构建使用 8GB Node 堆上限，默认 4GB 在扩展后的源数据编译时不足。浏览器验证了双团本背景卡、奥妮克希亚入口、地图首领数量和掉落详情；未宣称全仓库测试全部通过。
