# 40 人团本数值与职业伤害校准

基准：2019 Classic / 1.12 规则参考。当前可玩团本是熔火之心和奥妮克希亚；本次数据覆盖 11 名首领及 19 类护卫、小怪和召唤物。这里的“参考”是可追溯的社区实现，不代表取得了暴雪服务端数据。

团队容量为40人，人数可以不足40，但首领不会随人数缩放。三档真实装备与三种阵容的实战记录见 [40人挑战](../research/classic-40-raid-challenges.md)。旧 [T1坦克验证](t1-tank-benchmark.md) 是25人版本的历史记录，不适用于当前数值。

## 固定原始数值

`scripts/import-raid-combat-reference.py` 从固定 ClassicDB 归档提取生物模板、等级基础属性、完整的141条 `spell_bonus_data` 与等级链，并校验归档SHA-256。数据库版本为 [`22b51464f1625f6ef6275771de1f5466c6f5d19e`](https://github.com/cmangos/classic-db/tree/22b51464f1625f6ef6275771de1f5466c6f5d19e)。

| 项目 | 当前规则 |
| --- | --- |
| 血量与普通近战 | 原始倍率1；取消25/40生命缩放 |
| 等级、护甲、抗性、免疫、攻速和学派 | 保留对应生物来源值 |
| 法术伤害 | 从固定数据库的法术效果读取，不乘人数系数 |
| 随从和阶段 | 加尔8个火誓者，炎魔8个烈焰之子，炎魔180秒地上/最多90秒潜入 |
| 作战预算 | 15分钟后结束模拟并记录超时，保留生命值，不伪装成原版狂暴 |

`scripts/import-raid-spell-reference.py` 抽取213条首领/随从法术及触发法术。`raid-spell-reference.json` 保留版本、源文件URL与SHA-256。时序依据 [固定版CMaNGOS脚本](https://github.com/cmangos/mangos-classic/tree/8ec338a1704e7dcb1c0213eb7ed58f9231ade40f/src/game/AI/ScriptDevAI/scripts/eastern_kingdoms)。鲁西弗隆末日改为40码内目标、10秒后2000伤害；玛格曼达两类熔岩弹独立计时；其余首领分别保存技能冷却，不再使用统一15秒脉冲。

### 实现边界

这里的“原始”指上述可审计社区数据库与脚本，不能声称取得了暴雪服务端实现。场地几何、移动、奥妮克希亚飞行/深呼吸路径仍由本作模拟；部分次要技能、可打断施法、触发法术和控制行为尚未逐项复刻。恢复原始生命/近战、法术数值和主要阶段不等于完成全部原版机制。这些差异会影响实战结果，应继续按来源修正，不能为获得通关结果降低首领强度。

血量来自 `BaseHealthExp0 × HealthMultiplier`。z2815 数据的近战伤害使用等级表公式：

```
min = (BaseDamageExp0 × DamageVariance + BaseMeleeAttackPower / 14)
      × MeleeBaseAttackTime / 1000 × DamageMultiplier
max = (BaseDamageExp0 × DamageVariance × 1.5 + BaseMeleeAttackPower / 14)
      × MeleeBaseAttackTime / 1000 × DamageMultiplier
```

不能把模板中的旧 `MinMeleeDmg` 当成已完成倍率结算的伤害，也不能在上式之后再次加基础攻击强度。此公式对应现有归档的旧等级表结构；新版核心已经更换了结构，不能直接混用新版字段。

例如鲁西弗隆为 351,780 生命、3,795 护甲；奥妮克希亚为 1,099,230 生命、4,691 护甲。萨弗隆为 5,864 护甲。迦顿男爵与炎魔的火焰免疫不再被工厂丢弃。召唤物不再全部被强制变成 63 级首领。

## 系数与统一伤害结算

`scripts/import-classic-spell-coefficients.py` 从 [WoWSims Classic 固定版本 `7779ebbf`](https://github.com/wowsims/classic/tree/7779ebbf79dc7f1341e6ab939b28a3402c9a730a/sim) 的 40 个源文件提取 276 个技能等级的系数。输出保留每个文件的 URL、SHA-256、直伤/每跳系数及二元/纯 DoT 分类。每等级数值已经包含低等级惩罚，执行时不得重复扣减；奥术飞弹的伤害子法术继承引导等级的系数。

优先级是：精确等级记录 → 完整数据库中的显式记录/等级链 → 固定核心默认公式。默认公式按原始施法时间、持续时间、跳数、直伤与持续部分的分摊、范围、吸血和附加效果计算，仍属于参考估算，不能宣称所有技能已逐条实测。

已校正的实例包括献祭每跳 0.13、腐蚀术高等级每跳 0.167、心灵鞭笞每跳 0.15、月火术直伤 0.15/每跳 0.13、烈焰震击直伤 0.214/每跳 0.1，以及低等级寒冰箭 0.163。审判现在加入法伤；命令圣印使用实际触发技能、7 PPM 和 1 秒内部冷却，伤害按 `0.7 × (武器伤害 + 0.29 × 法伤)` 处理。命令审判对未昏迷目标使用一半基础伤害，再叠加法伤，防止把 Boss 当成可昏迷小怪而高估输出。神圣近战技能仍使用近战暴击率和双倍基础暴击伤害，不能仅按伤害学派判断暴击类型。

风怒额外攻击走物理白字攻击表（命中、闪避、招架、偏斜、暴击），按 1.5 秒内部冷却处理，不再受法伤加成。元素武器仅放大额外攻击强度。火舌武器按 0.1 法伤系数结算一次，并使用火焰法术命中；攻击图腾使用实际伤害子法术的系数和命中。

物理命中区分未命中基础值和命中压制：300 武器技能对 315 防御有 8% 基础未命中，但第一点百分比命中被压制，所以需 9% 装备/天赋命中封顶；305 技能只需 6%。双持白字单独增加 19%。Boss 的近战暴击压制不因装备武器技能加成而消失。

## 魔法抗性

概率档位参考固定版本的 [spell_resistances.go](https://github.com/wowsims/classic/blob/7779ebbf79dc7f1341e6ab939b28a3402c9a730a/sim/core/spell_resistances.go)，其分段函数是对实测档位的拟合；它不是官方概率表。

- 法术命中/全抵抗与命中后的部分抵抗分开。二元法术把抗性计入初始命中，成功后不再扣一次部分抵抗。
- 非二元魔法在共同伤害路径中随机结算 0%、25%、50%、75% 抵抗，直接伤害、持续伤害及触发伤害共用结算；抵抗发生在吸收前。
- 减抗和法术穿透只降低对应学派的显式抗性，下限为零；对高等级 NPC 的等级抗性不能被穿透移除。
- 非二元法术对高 3 级 NPC 保留 6% 的等级减伤参数。概率拟合后的实际期望值略有差异，测试按档位而非声称精确 6% 验证。
- 纯 DoT 的显式抗性按十分之一计算，等级惩罚仍保留；混合直伤/DoT 不套用纯 DoT 规则。
- 神圣学派不使用显式抗性，但非二元神圣伤害仍适用等级项。
- 伤害日志记录 `resisted` 和 `resistFraction`；生命扣除、仇恨和伤害统计使用减伤后的实际伤害。随机数来自同一个可序列化种子状态。

## 配装

持久 NPC 的整套配装评分使用 `stats()` 的职业换算，不再维护“只有战士的力量有价值”的另一套规则。输出包括攻击强度、武器 DPS、武器技能与偏斜、物理/法术命中、暴击，以及实际策略对应的学派法伤。增强萨和惩戒骑兼顾物理与法术收益，防骑也考虑法术仇恨装备。命中收益按当前技能、双持状态及技能命中天赋封顶；野性形态忽略武器面板 DPS。双戒指、副手损失和唯一装备约束继续参与整套比较。

旧的未使用 `gearScore` 已删除，避免继续作为配装依据。评分权重、策略中各伤害技能等权分摊仍是启发式；饰品触发、循环占比、资源耗尽、具体首领学派差异尚未进行逐候选装备的完整战斗优化。

## 验证边界

`raid-calibration.test.ts` 覆盖来源数值、缩放、免疫、主要职业技能系数、抗性与穿透、攻击表上限、神圣武器暴击、混合职业配装和序列化确定性。演示与金团集成测试验证同一个战斗引擎。

这次修改不等于完成了全部首领脚本、宠物/触发物品、历史服务器批处理或所有天赋组合的官方实测复刻。后续校准应补充逐技能日志和参考误差，不应为了让某次模拟通过而暗改 Boss 护甲或玩家伤害倍率。
