# 团本房间与机制联动

当前开放团本为熔火之心十首领和奥妮克希亚，团队容量为 40 人。全部 11 位首领使用独立多边形房间，沿用新版奥妮克希亚的空间规格。房间是以码为单位设计的单层战斗场地，不是原版地图碰撞网格；首领生命、攻击和法术数值继续使用固定参考数据，不按人数缩放。

## 统一房间规格

`packages/game-data/source/boss-rooms.json` 是房间唯一设计源。每个房间有独立边界、名称、配色和语义锚点。编译脚本校验边界与锚点，输出导航三角形、邻接门户、包围盒和内容摘要到 `data/boss-rooms.json`。准备队列、实际战斗、AI 寻路、视线、移动裁剪和前端地面共用这份数据。

熔火之心使用 `entrance`、`assembly`、`boss`、`mainTank`、`melee`、`ranged`、`offTank`、`adds` 和两侧炸弹撤离锚点；炎魔房间另有八个烈焰之子出生点。奥妮克希亚保留其龙巢、雏龙出生点和深呼吸路线。实际落点需要满足单位净空，护卫、宠物和图腾也必须留在地板内。

普通移动和击退裁剪经过的线段，不能穿墙；传送、召唤和复活使用合法目的点投影，不把出生过程误当成从旧坐标开始的行走。准备画面根据当前首领房间或路线选择对应房间，投影读取不改变模拟状态。

## 机制几何与展示

`packages/sim-core/src/encounter-geometry.js` 定义圆形、多边形、螺旋带、矩形通道和扇形。多边形点是绝对战斗坐标，同一份点用于服务端伤害、AI 安全位置搜索和 Three.js 地面网格。

`raid-battlefield.js` 保存场地生命周期：`startedAt`、`armedAt`、`next`、`until`。`once` 表示一次爆炸，`terrain` 表示固定熔岩，`followId` 表示跟随单位。计时只依赖模拟时钟，暂停与 JSON 恢复不重置预警，伤害走统一结算管线。

自动躲避遵守避火开关、控制状态、成员反应和完成当前施法策略。不可规避机制不触发无意义跑位；固定熔岩约束普通接近，击退仍可能进入熔岩。开启避火并不免疫伤害。

前端消费服务端房间与危险范围。地面按导航三角形绘制，墙体沿真实边界，预警通过地面模板裁剪，不伸出洞厅。普通与简化特效均保留范围与倒计时。静态几何按房间摘要和投影复用，房间替换或卸载时释放资源。MC 的配色、火盆和雕纹仅用于展示，不产生额外碰撞或伤害。

## 验证与预览

```sh
npm run data:compile
npm run data:check
node --test packages/game-domain/test/boss-room.test.ts packages/game-domain/test/raid-room-layout.test.ts packages/game-domain/test/raid-room-summons.test.mjs packages/game-domain/test/raid-battlefield.test.ts packages/game-domain/test/classic-raid.test.ts
node scripts/verify-raid-rooms.mjs
node apps/web/scripts/serve-raid-battlefield-preview.mjs
```

预览入口为 `http://127.0.0.1:5207/battle-3d.html`，可选择所有首领、准备或战斗阶段及简化特效。预览只使用隔离演示数据，不写正式账号或存档。

`verify-raid-rooms.mjs` 对全部首领进行独立 40 人实际引擎拉怪，检查每个 100ms 时刻的存活单位是否在真实地板内，并比较 JSON 恢复后的完整状态。默认使用真实全史诗挑战配装、4 坦克、10 治疗与固定随机种子；记录自然胜负或 15 分钟模拟超时，不人为保命或降低首领属性。单次通过表示空间与恢复检查通过，不代表每种阵容均可通关或完成平衡认证。

本轮实测结果保存到 [房间验证记录](measurements/raid-rooms-2026-10-01.json)。这次改动包含可用空间与初始站位调整；历史矩形场地的通关记录不能替代新房间的结果。系统仍是统一 0.45 码净空的单层导航，不包含多楼层、高度、动态门、按体型寻路或原版 vmap/mmap。

2026-10-01 的完整 11 场独立拉怪共检查 524,947 个存活单位位置，全部在真实地板内；11 场 JSON 检查点恢复均与原时间线完整状态一致。固定阵容取得 6 胜 5 负，无模拟超时。炎魔实战覆盖潜地，奥妮克希亚实战覆盖升空与深呼吸；未在这次自然实战中到达的阶段由专项测试覆盖，不能据此宣称所有阶段都已自然通关。

当前黄金样本只更新了鲁西弗隆团本场景的空间、站位及后续行为；单人、五人本、竞技场和战场的所有完整状态哈希、RNG 与收益样本逐项保持不变。通用召唤落点的修复不会为没有导航缓存的新单位增加空字段。
