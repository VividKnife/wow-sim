## 数据与规则

`packages/sim-core/src/encounter-geometry.js` 定义圆形、多边形、螺旋带、矩形通道和扇形。多边形点是绝对战斗坐标（码），同一份点用于服务端伤害、AI 安全位置搜索和 Three.js 地面网格。圆形使用统一中心与半径。

`raid-battlefield.js` 负责可序列化场地生命周期：`startedAt`、`armedAt`、`next`、`until`。`once` 表示一次爆炸；`terrain` 表示固定熔岩；`followId` 表示跟随单位。计时只依赖模拟时钟，暂停与 JSON 恢复不重置预警，不依赖渲染帧产生伤害。伤害仍走原有 `hurt` 管线。

自动躲避遵守避火开关、控制状态、金团成员反应和完成当前施法策略。全场地震标为不可规避，不会让全团寻找不存在的安全点。固定熔岩额外约束普通接近行为；击退仍可进入熔岩。开启避火不等于无敌：反应延迟、定身或错误站位仍会受伤。

`battlePresentation` 把危险范围投影到客户端。3D 场景不自行推算机制；显示轮廓、预警/激活颜色和技能名倒计时。简化特效仅减少装饰粒子，所有机制范围仍显示。具名团本场地自动取景包含整个边界，战后保留固定地形。MC 的 SVG 试玩也消费同一几何数据。

## 验证与预览

```sh
node --test packages/game-domain/test/raid-battlefield.test.ts packages/game-domain/test/endgame-p1.test.ts
node --test packages/game-domain/test/raid-command.test.ts packages/game-domain/test/gold-world.test.ts packages/game-domain/test/gold-raid.test.ts
node apps/web/scripts/serve-raid-battlefield-preview.mjs
```

预览：`http://127.0.0.1:5207/battle-3d.html`。选择“拉格纳罗斯 · 螺旋熔岩”或“奥妮克希亚 · 深呼吸”查看暂停的真实机制快照，点击继续模拟观察战斗。预览不写正式账号或存档。

本轮验证：53 项团本/渲染回归通过（包含实际公会、金团和奥妮克希亚战斗）；随后 17 项场地、渲染与镜头复验通过。根目录与 Web 项目使用仓库根 TypeScript 检查器检查通过。浏览器已打开真实预览，但自动化连接中断，未完成最终画面的人工视觉验收。
