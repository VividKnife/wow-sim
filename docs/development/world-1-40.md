# 1—40 级世界扩展

本次将原先以北郡、艾尔文、西部荒野为中心的世界扩展为联盟与部落共同使用的地点图。当前共 220 个地点节点、36 个区域标签（包含主城、北郡和月光林地），14 条可进入的地下城路线。区域之间支持道路、船只、飞艇、地铁和飞行点；旅行耗时和路线是本项目的改编值。

这是一版可运行的节点式世界扩展，并非原版 1—40 所有内容逐条复刻完成。数据记录数不等于已逐条通关的任务数。地图美术、战斗模型和地下城手册已经接入本地资源；任务脚本、空间路线与部分首领机关仍有以下边界。

源 SQL 放在 `.cache/source-data/` 后运行：

```sh

```

导入器只解析 SQL 文本，不执行 SQL。中文导入器首次运行下载固定提交的文件。已提交的生成数据支持不联网启动。

## 玩法边界

### 地下城手册、地图与模型

- 手册覆盖 28 个副本/分区条目，其中 14 条路线可挑战。每张卡片均有对应本地背景，同一副本的不同翼共用该副本美术；详情使用首领侧栏、肖像、羊皮纸档案、技能与战利品、地图分页。首领掉落可搜索、按类型筛选、查看共享掉落，装备详情与游戏背包复用数据。
- 导入 28 张卡片背景、166 张地下城手册首领肖像，以及 24 张新增原版副本楼层地图；保留原有死亡矿井与监狱楼层。首领坐标由源出生坐标投影，楼层有针对性规则；遭遇路线仍是节点式改编，并非导航网格。
- 35 个区域/主城地图条目使用原版地图素材与 WorldMapArea 坐标范围。新增主城仍采用三个功能区节点，不能等同于全部街巷与建筑可进入。
- 战斗模型目录本轮导入后为 2,083 个 GLB，覆盖世界野外与 14 条路线当前使用的怪物显示模型，含新增首领召唤物。NPC 肖像目录登记 5,674 个生物、4,955 张显示肖像。非战斗 NPC 不保证全部有三维模型。
- 新增 3,159 项物品图标映射，显示物品等级、绑定、耐久、伤害/DPS、属性、抗性、职业/种族/专业要求、装备与使用效果。源站无法解析的 6 项图标仍未补齐，其中含调试/怪物持有物品；没有用无关图标冒充原图。
- 地图、技能说明和首领掉落按内容版本分包加载，不将完整源数据或全部掉落塞入初始手册。

### 首领与采集

- 已补充阿鲁高、杜安、赫洛德、瑟玛普拉格、阿扎达斯、莫格莱尼与怀特迈恩的源技能循环及关键阶段，保留重拳先生原有机制。包括杜安气泡后引爆、赫洛德旋风斩实际周期伤害与死亡后学员、步行炸弹自爆、石像守卫唤醒、大教堂假死—深度睡眠—复活双首领阶段。
- 这些脚本依据固定 CMaNGOS 版本改写到本项目引擎。召唤位置和场地仍有改编；诺莫瑞根六个机器按钮、阿鲁高传送和全部环境交互尚未逐项还原。
- 新区域草药与矿脉按源对象出生点、掉落和 Lock 技能要求接入，保留熟练度门槛、采集耗时与冷却。资源收获数量、地点粒度及刷新仍沿用本项目规则；钓鱼尚未逐区还原全部鱼群。

### 仍需逐项还原的内容

- 已有专门实现的探索、迪菲亚护送和暴风城任务事件保留。其他脚本类任务采用界面明确标注的计时场景，要求接受任务、到达地点、持有必要任务物品并等待，支持中止与恢复。某些召唤目标进入真实战斗；普通击杀不会代替任务法术目标。
- 未有来源的任务专用物品使用任务场景适配。这不等于原版的对话、护送路径、机关、变身或召唤仪式已全部实现。
- 职业任务交付会按职业覆盖登记发放对应技能。训练师仍提供项目原有的职业解锁改编入口；尚未强制所有职业能力都只能通过原版完整任务链解锁。
- 地点归属按同一大陆的最近节点计算，地形是示意路线；部分边界生物、节日人物和服务点还需要逐区细化。飞行线路也使用改编的主城枢纽图，并非原版全部航线。
- 部分区域音乐复用已有本地主题资源。未知或不在当前战斗目录的生物模型仍有明确的回退显示。
- 源 AI 数据接入现有引擎支持的动作，不能代表所有 ScriptDev 首领技能和机关已经实现。专项副本测试验证入场、有限数值、首场战斗与进度恢复，并未验证每个新副本的完整平衡通关。
- 完整 1—60 世界不在此实现内；高等级手册条目不代表已经能进入对应副本。
