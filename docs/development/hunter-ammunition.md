# 远程弹药与城镇自动购买

- 角色页面在远程武器右侧显示弹药栏、当前选用的物品和同种弹药数量；点击可定位背包物品。箭矢和子弹是普通背包实体物品，占用格子，射击直接扣减，耗尽后删除空堆叠。选用弹药不会转移或复制物品。
- 1 级猎人按种族获得弓/枪、200 发匹配弹药，以及默认开启的 400 发补给目标。手动选用必须满足等级、武器类型、归属、未锁定和非配发条件。当前选用品耗尽或不再匹配武器时自动使用背包内最高档可用弹药。
- 所有职业共享「城镇自动购买」。通过 GameSelect 添加商店物品、设置目标个数、开启/关闭或移除；最多 32 项，每项目标为 1—10000 的整数。选项优先显示本职业弹药、施法材料、适用食物与饮水；不引入拍卖行货源。箭矢和子弹各只有一个补给选项，实际购买当地商店出售、当前等级可用的最高档。
- 自动购买是客户端插件行为。服务端 `townSupplySettings` 只保存设置，回城只递增访问标记；普通 `buy` 是唯一购买入口，`selectAmmo` 只选用已有弹药。服务端仍校验价格、背包容量、金币和操作状态。页面关闭时不会自动购买。
- 客户端在城镇打开页面、抵达城镇或修改设置后执行补给，逐次读取已接受的最新快照，按商店整组购买至目标。余额不足时跳过买不起的物品；购买失败停止本轮并使用普通错误提示。中断后重新打开页面或下次回城按实际库存继续，不重复购买已收到的物品。离开城镇、切换角色、进入战斗或修改设置会结束旧流程。
- 背包一键丢弃/售卖灰色垃圾排除弹药；手动出售、转移和丢弃仍可正常使用。NPC 和演示角色也使用背包弹药，补给费用由各自 NPC 规则管理。
