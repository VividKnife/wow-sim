# 战斗掉落与拾取

怪物掉落先按正常掉落表掷骰，物品存入 `pending`，用 `lootBattleId` 标记来源战斗。战斗结束后显示经典风格战利品窗口。金币仍即时记入钱袋，结算窗口显示本场金额。未拾取物品持久保存，满包不会丢弃；连续狩猎等待待拾取物品清空后继续。

`loot` 命令不传 `uids` 时领取全部，传入 UID 数组时仅领取指定物品。已领取或不存在的 UID 不产生奖励。转入背包时保留绑定、附魔、耐久等实例属性，清除掉落来源字段，再按同属性物品合堆。战斗中禁止拾取。

`settings.autoLoot` 默认为 false，勾选状态随角色保存。开启后，客户端在窗口实际显示 1500 毫秒后提交一次拾取命令；关闭窗口或关闭自动拾取会取消计时。背包满或网络失败不会循环重试，可手动重试。离线期间保留掉落，重新打开游戏后展示并领取，避免后台推进跳过预览。

验证：`node --test apps/web/test/loot.test.mjs`。浏览器独立夹具：`apps/web/test/browser/loot.html`。
