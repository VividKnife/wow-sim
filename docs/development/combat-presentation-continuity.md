# 战斗画面连续性

2026-10-01：当前体验目标是稳定 30 FPS，优先消除技能画面停顿与随后快进，平均 FPS 不能替代连续性验收。

## 原因与修改

原显示时钟在缺包一秒后停止推进，收到更大的服务器时间又立即跳到该时间。Canvas 还在 HUD 已经外推过的时间上再次外推；HUD 重渲染会重建采样时间。读条组件使用服务器时钟作为 React key，每个包都会重新挂载计时器，迟到的包可能让同一次施法从更早的百分比重新开始。

- HUD 和 Canvas 直接以服务器时间采样，各自连续读取显示时钟，不把 HUD 的外推值作为第二次外推的输入。采样时间仅随真实模拟时间、遭遇或暂停状态更新。
- 普通显示时钟允许三秒的短暂外推，校正速度限制在正常速度的 90%–110%；新包到达的那一刻不跳时钟。暂停/恢复、遭遇切换独立重置锚点，录像仍受录制终点限制。
- 同一次读条不因服务器时钟变化而重新挂载；已知施法期限自行推进到结束并收起，不等待完成回执。施法被打断或结束后，服务器状态仍能立即移除读条。
- 延迟包只展示最近 600ms 的新增技能特效，避免将几秒前的攻击同时补播。完整战斗日志、伤害和结算未减少。

这些变化只涉及展示。未知的下一次施法、伤害、命中、奖励与位置不在客户端推演。超过预测窗口的长时间停服仍可能停止已知计时；后端持续落后不能仅靠显示时钟修复。

## 验证

自动化回归覆盖 30 FPS 下两秒连续缺包、延迟包校正上限、重复包、长时间缺包上限、暂停/恢复、遭遇切换、录制边界、移动插值、技能动画及旅行/复活进度。53 项通过，根目录 TypeScript 检查通过。

真实浏览器读条测试：三秒火球术，1.2 秒时收到仅代表 0.6 秒模拟时间的迟到状态，之后不发送完成回执。实际读条倒退次数 0、DOM 替换次数 0、单次采样最大增量 2 个百分点，3213ms 自动结束。页面为 `cast-continuity.html`，通过“测试延迟读条”按钮复现。

真实 HTTP/WebSocket 战斗预览可使用：

```sh
PREVIEW_SCENE=raid PREVIEW_BUILD=1 PREVIEW_JITTER_MS=1600 node apps/web/scripts/serve-live-combat.mjs
```

每八秒人为延迟一次状态生成 1600ms；`live-combat.html` 的 HUD 记录帧间隔、长任务、断线和最大收包间隔。预览单次规则推进预算由 100 步调整为与正式 worker 一致的 10 步，避免测试进程在 CPU 竞争时长时间集中补算。首次使用旧 100 步预算的测试出现断线，不计为通过；改成 10 步后曾连续运行 87.8 秒零断线，最大收包间隔 2713ms（含战斗结束后的时间，因此不作为战斗帧率样本）。

这是本机生产前端构建、内存实例、真实 HTTP/WS 的体验测试，不含 PostgreSQL、独立 Worker 池或目标服务器容量测试，也不是已经上线的结果。

最终带延迟的战斗运行样本为 55.8 秒，40 人编队自然战斗（有成员阵亡），236 条增量、零断线、零控制台错误，最大收包间隔 1820ms。最近 1800 帧间隔 P50 16.7ms / P99 32.1ms，整段采样出现一次长任务；这是含真实网络空窗的连续战斗显示样本，不能据此声称全设备稳定 30 FPS。数据见 `measurements/combat-continuity-2026-10-01.json`。

## 后端推送调度与订阅切换

主线提交 7192067e 已接入 `createPublicationLoop`：每连接最多一个投影请求和一个定时器，下一次发布从本次开始时间计算。移除固定间隔回调内的第二次 100ms 门槛检查；耗时投影结束后让出事件循环，再请求最新状态，不补发积压的历史帧。处理中收到重新订阅会合并成一次强制完整基线；旧订阅的结果或错误不能覆盖/关闭新的订阅。

调度与真实 HTTP/WebSocket 回归 27 项通过；新增真实 socket 测试分别将旧角色的成功结果和 403 错误阻塞到新订阅安装后释放，均只收到新角色基线，连接保持开放。根目录与 Web 目录 TypeScript 检查通过。

主线生产前端构建的 40 人团本浏览器样本：35.3 秒，275 条增量，约 7.79Hz，最大收包间隔 407ms；0 断线、0 控制台错误、0 长任务，最近 1800 帧 P50 16.7ms / P99 34.1ms。仍未达到稳定 10Hz 发布，也不能宣称 P99 稳定 30 FPS；投影成本仍是后续工作。此轮没有注入网络延迟，也没有 PostgreSQL 或独立 Worker 池，不能与之前不同负载轮次做严格性能归因。数据见 `measurements/publication-loop-browser-2026-10-01.json`。
