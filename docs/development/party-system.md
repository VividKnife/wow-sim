# 队伍系统

## 当前规则

- 主角18级自动领取任务900001「同路人」，暴风城贸易区旅店老板奥里森（6740）交付；其他城镇不能完成。任务不可放弃，完成后永久解锁。
- 在暴风城贸易区招募，账号最多四名长期队友。`recruit` 和带自定义名字的 `createCompanion` 使用同一权威初始化流程，无法绕过任务、地点或名额校验。
- 九种职业可选其支持的坦克、治疗、近战输出或远程输出职责。等级与招募时主角相同，技能按等级和种族学习，天赋按职责天赋树的合法层级与前置条件分配，并应用职业策略。18级野性输出暂用熊形态；猎人获得同级森林狼待召唤。
- 初始套装为本作任务改编的18级绿装（目录990000段），不是原版掉落。护甲、饰品和戒指使用固定属性，武器从可穿戴的绿色原版目录中选择；衬衣、战袍以及该职业无法使用的栏位不配发。外观与图标引用真实来源物品。
- 两项自选生活职业均为75/75；沿用现有熟练度自动解锁配方规则，后续可正常进阶。队友总计最多两项，包括采集、制造和副职业。默认采药与炼金。
- 队友非战斗状态下可免费洗点，不要求前往训练地点；副本或被其他活动占用时沿用活动操作限制。主角仍使用原有洗点费用。

## 更换与持久化

`recruit` 带 `replaceId` 更换当前队伍中的长期队友。每次100000铜（10金币），重复请求按requestId幂等。必须由主角发起，目标必须归队且无活动租约或预留制造资产。

队友席位保持稳定角色ID，新的招募代数会重建职业、技能、天赋、策略与状态；既有背包、银行、金币保留。旧装备逐件验证栏位、熟练度及双手/副手冲突。可用物品保留实例ID、附魔与耐久；不可用装备回到主角背包，空位配发绿装。空间及余额不足整笔事务回滚。物品所有权转移先于角色资产写入，避免复制或删除已转移装备。

角色页选择器加载对应角色的权威快照，所有六个分页沿用选中角色的characterId发命令。

## 验证

`packages/game-domain/test/party-recruitment.test.ts` 覆盖等级任务、九职业职责初始化、队伍组成、非法选项、装备继承/退回、背包满回滚、余额及重试幂等、持久化和免费洗点。
