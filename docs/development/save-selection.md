# 账号与独立存档

登录后 `/` 显示该账号的存档列表；`/?saveId=…` 进入指定存档。每个存档有独立主角、队友、队伍、装备、任务、钱包和后台活动。游戏、回放和工坊请求均明确传递 saveId，不使用浏览器共享的“当前存档”值，因此不同标签页不会相互切换。

角色选择采用右侧名单、中央人物、底部进入游戏按钮的经典布局。选中角色后通过带 `saveId` 的已认证游戏快照读取真实装备，再按快照的内容版本获取物品外观；不使用初始职业套装替代存档装备。切换角色取消旧请求并卸载旧模型。模型资源失败可重试，不阻止进入游戏。

创建页、选择页与装备页共享 `CharacterModel`。创建角色时可选择男或女，性别随角色持久化；Classic 模型 ID 分别为 `raceId * 2 - 1`（男）和 `raceId * 2`（女）。职业、性别及实际装备通过同源 iframe 消息传入，角色选择页和装备页继续使用存档中的性别。当前没有捏脸存档字段。创建预览从只读 `/api/character-preview` 获取，由与创建存档相同的初始化/直升逻辑生成，不写入存档。资源来自现有 Wowhead Classic 中转，网络中断或 502/503/504 自动重试一次，失败时显示提示。

独立视觉验收：`node apps/web/scripts/serve-character-create-preview.mjs`，访问 `http://127.0.0.1:5181/character-create.html`。该页面使用人类法师与牛头人战士测试存档数据，模型资源真实加载，不读写用户存档。

Web 会话认证后由服务端签发短期身份令牌。`/saves` 提供查询、创建和删除；游戏服务根据令牌主体及存档的 userId 验证归属，客户端提供的账号字段不能覆盖身份。创建请求幂等，上限 20 个存档。删除须在界面二次确认，事务清理全部关联资产、活动与租约；涉及共享副本时结束副本并释放其他成员。旧开发账号数据不迁移。

## 测试直升设计

- 创建全新 20 级、0 当前经验的存档，不覆盖已有存档。
- 创建时额外发放 50 金币（500,000 铜），普通 1 级角色不获得此奖励。
- 位于闪金镇，炉石绑定闪金镇；不完成普通任务，不招募队友。
- 达到18级自动开通队友系统，可在队友页随时招募或更换，无需任务或前往指定地点。
- 学会本种族、本职业 20 级以内不依赖天赋的训练师技能及武器训练；天赋点保留供玩家分配。
- 装备优先取自当前游戏数据中任务等级、最低等级均不超过 20 的实际任务奖励，并通过职业、种族和装备要求过滤，按属性挑选。当前原版任务库缺少的头、颈、肩、戒指、饰品部位，沿用项目已有的 18 级队友配发装备模板补齐，属于本项目改编装备。测试赠品绑定主角，不属于队友资产，也不视为完成来源任务。双手武器不同时装备副手。
- 四个 14 格符文布背包（14046），连同基础背包共 72 格；生命和法力补满。

礼包由游戏服务生成，浏览器只能指定角色名、合法职业/种族及是否直升，不能提交任意等级或物品。

- 直升另赠一匹旅行棕马（移速 +60%）并学会骑术，全部种族可直接召唤，无需声望；仍受20级、战斗、室内、游泳等骑乘限制。仅创建直升存档时发放，普通新建角色不赠送，商人不出售。
