# 账号与独立存档

登录后 `/` 显示该账号的存档列表；`/?saveId=…` 进入指定存档。每个存档有独立主角、队友、队伍、装备、任务、钱包和后台活动。游戏、回放和工坊请求均明确传递 saveId，不使用浏览器共享的“当前存档”值，因此不同标签页不会相互切换。

Web 会话认证后由服务端签发短期身份令牌。`/saves` 提供查询、创建和删除；游戏服务根据令牌主体及存档的 userId 验证归属，客户端提供的账号字段不能覆盖身份。创建请求幂等，上限 20 个存档。删除须在界面二次确认，事务清理全部关联资产、活动与租约；涉及共享副本时结束副本并释放其他成员。旧开发账号数据不迁移。

## 测试直升设计

- 创建全新 20 级、0 当前经验的存档，不覆盖已有存档。
- 位于闪金镇，炉石绑定闪金镇；不完成普通任务，不招募队友。
- 自动接取 18 级的“同路人”，尚未解锁队伍。前往暴风城旅店交付后，自行选择队友。
- 学会本种族、本职业 20 级以内不依赖天赋的训练师技能及武器训练；天赋点保留供玩家分配。
- 装备优先取自当前游戏数据中任务等级、最低等级均不超过 20 的实际任务奖励，并通过职业、种族和装备要求过滤，按属性挑选。当前原版任务库缺少的头、颈、肩、戒指、饰品部位，沿用项目已有的 18 级“同路人”任务配发装备模板补齐，属于本项目改编装备。测试赠品绑定主角，不属于队友资产，也不视为完成来源任务或解锁队伍。双手武器不同时装备副手。
- 四个 14 格符文布背包（14046），连同基础背包共 72 格；生命和法力补满。

礼包由游戏服务生成，浏览器只能指定角色名、合法职业/种族及是否直升，不能提交任意等级或物品。

- 直升另赠一匹旅行棕马（移速 +60%）并学会骑术，全部种族可直接召唤，无需声望；仍受20级、战斗、室内、游泳等骑乘限制。仅创建直升存档时发放，普通新建角色不赠送，商人不出售。
