# 暴风城分区主城交付与验证

日期：2026-09-16。

## 功能

- 8 个城市地点，城区预览、地图标点、服务指路、真实计时移动。
- 贸易区银行、模拟拍卖、补给、旅店、狮鹫服务；法师区保留共享路线训练站，其他城区新增对应职业训练入口。
- 城内就地展开银行、拍卖、训练、专业工坊、商店、炉石及交通面板。
- 整备清单随背包、材料、生命法力、炉石和飞行点实时更新。
- 新增矮人区、教堂广场、花园、暴风要塞；范克里夫信件交付者巴洛斯位于教堂广场，弗伦长须归矮人区，克劳雷修士归教堂广场。地图节点和道路为现有二维玩法适配。
- 矮人区连接 3 分钟矿道地铁；出城支持闪金镇、哨兵岭和铁炉堡。
