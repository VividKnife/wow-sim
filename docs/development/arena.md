# NPC 竞技场实现

2026-09-22。入口位于主导航「地下城」下方。主角18级解锁；使用同级且存活的真实伙伴，2v2、3v3、5v5均开放，默认3v3。

## 可用流程

选择人数、队员、NPC队伍和地图 → 不限时准备 → 保存战术或直接开始 → 3秒开门 → 自动战斗 → 胜负与伤害/治疗统计。准备没有超时或自动开始；10分钟仅是战斗上限。支持取消准备、投降和再次挑战。本期无积分、赛季、奖励或真人匹配。

两张原创地图：双柱庭院、四柱角斗场。三组NPC模板：银月试炼队、赤砂突击队、暮光织法者。对手采用现有伙伴生成器生成同级角色、技能、天赋与装备，并非怪物模板。

战术支持集火对象、后续击杀顺序、免疫转火、独立控场对象、持续压制、保护队友、控制接力顺序、逐人打断职责、低血量回撤、追击距离、初始阵型与多轮爆发窗口。角色仍需满足已学且启用的技能、冷却、资源、装备、距离和形态要求；保护任务优先尝试控制正在攻击支援对象的近身敌人，治疗继续沿用职业治疗优先级。控场目标与持续压制对象冲突时拒绝保存。

## 独立 PvP 配置与战前指挥

入口为「竞技场 → PvP 天赋与技能」。主角及所有自有伙伴分别保存 `pvpProfile`，包含版本、名称、职责、天赋分配与技能条件优先级。没有手动保存时自动使用本职业推荐配置；九职业各提供一套经典 60 级、51 点模板，低等级按实际点数预算截取合法前缀。推荐只使用已学普通技能，所选天赋授予的主动技能匹配当前等级的技能等级。

进入竞技场时，在参赛角色副本上重建 PvP 天赋和技能策略；原冒险天赋、技能、装备及策略不被覆盖。准备期间可以保存配置，已参赛成员立即重建并递增战术版本；倒计时和战斗期间配置锁定。配置随成员持久化，服务重启后保留。天赋校验职业、受支持状态、整数等级、层级、前置和点数上限；技能规则使用现有策略校验。

- 指挥器位于 `rules/arena-tactics.js`。集火目标死亡后按击杀顺序接续；启用免疫转火时暂时跳过全法术学派免疫目标，控场目标留到最后处理。
- 控制顺序每次只挑选一个可施放成员，保留正在读条及尚未结束的控制，按递减后的预计时长筛选；对持续伤害会立即打破的控制，避开已有 DoT 的目标。只协调成员已启用的技能，不会重新启用被禁用的控制或打断。
- 打断可设置关闭、集火对象、敌方治疗或任意施法者；每个施法目标只预留一名打断者，实际施法可以指向非集火目标。装备和形态检查复用职业技能准备逻辑，避免无盾战士抢占盾击任务。
- 「控场后爆发」持续检查每轮控制或封系剩余时间，只有达到设定窗口才释放进攻冷却；可选最低 1/3/5 秒、最长等待 8/12/20 秒。等待超时恢复进攻，避免无限保留冷却。防御与普通输出仍按自身条件执行。战斗页与日志显示等待、爆发和转火状态。
- 回撤增加到达支援范围后的恢复阈值，避免边界处反复切换；援护任务优先控制威胁指定队友的近身敌人。

模板是结合项目技能支持情况的推荐方案，并非声称逐项复刻最优实服配点。职业思路参考 [经典法师 PvP](https://www.icy-veins.com/wow-classic/classic-mage-pvp-guide)、[经典牧师 PvP](https://www.icy-veins.com/wow-classic/classic-priest-pvp-guide)、[经典战士 PvP](https://www.wowhead.com/classic/guide/classes/warrior/fury/dps-pvp-arena) 与 [经典盗贼 PvP](https://www.wowhead.com/classic/guide/classes/rogue/dps-pvp-arena)，核对日期 2026-09-22。竞技场编制、自动配置切换与战术指挥属于本作扩展，天赋采用经典 60 级天赋树，不引入现代版本的独立荣誉天赋栏。

## 实现边界

- `rules/arena.js`保存双方独立角色快照、计划、随机状态、投射物、日志与统计。两队轮流进入同一个`combatTick`角色执行流程，跳过怪物AI、仇恨选敌和PvE掉落。竞技中的生命、装备消耗与死亡不修改冒险角色。
- `pvp-runtime.js`补充角色/形态目标类别、禁用技能与控制配置；`sim-core/pvp-control.js`管理目标共享的控制递减、结束计时、伤害破控和免疫。法术命中使用玩家目标参数，物理攻击不对角色产生偏斜；护甲、伤害减免、护盾、治疗、资源、打断和冷却走原有技能结算。
- `arena-space.js`进行圆柱视线判定、可见图绕障路径与连续移动碰撞；普通攻击和目标技能起手/读条完成检查视线。发出的投射物保留原有命中语义，不把所有飞弹强制撞柱。地面与范围技能继续沿用各自效果中心规则。
- 准备推进只更新外部时间，不改变场内时钟、随机数或队伍。比赛与准备草稿通过既有个人活动存储。浏览器Worker与服务端都调用同一份规则；快照只显示感知投影，检查点保留完整模拟。
- 保存和开始要求匹配场次ID及计划revision；配置冻结后不允许更改。请求重试沿用服务层幂等机制。
- 正式战斗和结算画面复用`BattleHD2D`角色渲染；仅准备与地图预览保留俯视示意图。`arena-battle-scene.js`把公开竞技快照转换为共用场景，沿用角色精灵、动画、读条、弹道、伤害数字与变羊表现。立柱位置和半径直接来自模拟地图；隐藏敌人及关联特效不会进入场景。投射物ID包含施法者ID，避免双方序号相同导致渲染冲突。

## 与完整魔兽PvP还存在的差距

本版是经典旧世规则接入，并不等于全部技能逐项完成暴雪实服一致性认证。必须保留这些差距，不能把推测写成已验证行为：

- 控制递减的15秒结束后重置和分组以项目固定的 [CMaNGOS Unit.cpp](https://raw.githubusercontent.com/cmangos/mangos-classic/8ec338a1704e7dcb1c0213eb7ed58f9231ade40f/src/game/Entities/Unit.cpp) 与 [SpellMgr.cpp](https://raw.githubusercontent.com/cmangos/mangos-classic/8ec338a1704e7dcb1c0213eb7ed58f9231ade40f/src/game/Spells/SpellMgr.cpp) 为社区参考。当前注册控制统一以20秒为最长PvP时长、再应用递减；逐技能例外仍需补证。恐惧/定身的伤害破控使用与伤害占最大生命比例相关的概率，尚未核验为实服公式。
- 保留共用引擎现有抗性减伤近似，尚未完成全部二元/部分抵抗表、所有驱散抵抗及职业例外的逐项PvP验证。
- 心灵控制与地狱火的所有权转换还不能安全进入双队角色执行，竞技中明确禁用，不回退到怪物逻辑。未额外授予万能PvP饰品。
- 100ms步长交替双方先手，保证分段与恢复一致；尚未实现严格同时事件批处理。
- 保护任务和回撤是规则 AI，没有动态地形评分或自然语言战术解释。战报提供近期日志与全场累计统计，尚无完整时间轴回放。

## 验证与预览

`node --test packages/game-domain/test/arena.test.ts`覆盖14项：准备冻结、非法阵容/计划、倒计时、双方角色战斗、冒险状态隔离、分段和JSON恢复一致、三种人数/三种NPC含宠物、投降、柱体与路径、变形目标、共享递减、免疫与破控、触发控制/护甲、服务重启和本地检查点。

另运行经典攻击、空间、变形、职业技能、天赋、策略、导航和统一下拉框回归，共189项通过。旧变形测试将近身目标设为9码时只改变了X，当前出生点已有Y偏移；补上Y=0，使其确实验证10码内的规则条件。

`npm run typecheck`与`npm --prefix apps/web run build`通过。

HD-2D接入另通过39项竞技场与共享渲染回归，覆盖公开技能/特效投影、角色和变羊素材、立柱坐标、隐藏单位、跨队投射物及结算时钟。浏览器实测5v5四柱战斗、技能动画和角色选择，控制台无错误。

绕柱修正：接近寻路拐点时，只有到下一节点的整段路径满足角色碰撞半径才提前切换；缓存中的下一段被阻挡时立即重算。使用实际卡住场次的坐标验证战士在首个集火目标死亡后绕柱接近新目标并恢复伤害，另覆盖两张地图全部立柱的多方向连续移动与失效路径缓存。竞技场及共享移动回归24项通过。

运行`node apps/web/scripts/serve-local-simulation-preview.mjs`后打开`http://127.0.0.1:5192/local-simulation.html?saveId=preview:arena`。预览采用内存存档、真实GameService、生产Game组件及本地Worker；不会写入正常账号数据库。

浏览器实测：桌面1280px与手机390px布局，导航顺序、3v3队员切换、阵型保存、主动开战、实时战斗、投降结算与5v5准备。预览入口同步加载生产`journey.css`后，390px无页面横向溢出；页面无原生select。

PvP 配置与指挥增强另新增 `packages/game-domain/test/pvp-configuration.test.ts` 的 14 项测试：九职业 10–60 级推荐配点、天赋技能等级、冒险状态隔离、准备同步与版本冲突、战斗锁定、非法配置、成员持久化、禁用技能、递减与 DoT 避让、接控预约、非集火打断、无盾打断让位、真实战斗封系、多轮爆发、转火及援护。与竞技场、共享场景、策略及天赋回归合计 75 项通过。浏览器验证队友修改天赋/技能后刷新保留、推荐方案恢复、准备区自动应用、战术保存、3v3 完整战斗、战中锁定及战后解锁；390px 配置页无横向溢出、无原生 select。预览内容接口同步使用生产 `contentPack` 协议。
