# Classic 战斗规则实现与验证边界

更新：2026-09-17。版本基准见 [version-baseline.md](../design/version-baseline.md)：2019 Classic Phase 1，使用 1.12 资料作为参考。这里描述当前实现，不代表已经复刻暴雪服务端，也不以技能数据条数代替机制覆盖率。

后续效果执行器、光环生命周期、逐技能与天赋验证清单见 [spell-runtime.md](spell-runtime.md)。

## 执行与时间

单人、队伍成员、宠物和敌人在服务端领域模拟中结算；客户端展示快照与战斗事件。模拟使用种子随机数及模拟时间，保存、恢复和分批推进必须保持一致。空间层仍采用项目现有二维模型；本轮不扩展地图碰撞和寻路。

`spell-timing.js` 分离四种状态：

| 状态 | 当前规则 |
| --- | --- |
| 技能冷却 | 按技能等级链的根技能保存；切换等级不能绕过冷却 |
| 共享冷却 | 按数据中的 `Category` 保存，震击等共享恢复时间 |
| 公共冷却 | 按 `StartRecoveryCategory/StartRecoveryTime` 启动；支持 1 秒、1.5 秒和不触发 GCD 的技能 |
| 读条占用 | `cast/nextAction` 仅表示施法占用，与 GCD 独立 |

普通读条开始时启动 GCD，成功释放时扣资源并启动技能及类别冷却；取消、目标失效或超出射程时不提交这笔消耗。瞬发和引导开始时提交消耗与冷却。成功提交具有幂等性。弹道飞行不会再次扣资源或消耗一次性施法增益。只有实际花费法力的法术重启五秒回蓝规则。

急速和天赋先修改施法时间；法伤系数仍基于原始技能。气定神闲等一次性增益在成功释放时消费，并保存本次法术需要的触发状态。寒冰屏障等实际技能冷却与 GCD 分开；急速冷却、伺机待发同时清理相应技能和类别冷却，不清除 GCD。伺机待发使用 Classic 盗贼技能族规则，包含剑刃乱舞。

## 数值结算

- 武器攻击使用武器技能、防御技能、命中以及各自的闪避、招架属性；双持普通攻击有独立的未命中惩罚。普通攻击的未命中、闪避、招架、偏斜、暴击等使用互斥攻击表；物理特殊技能命中后单独判断暴击。敌人攻击的格挡、暴击和碾压互斥。
- 主副手分别计时；副手有伤害惩罚并接受对应天赋修正。熊、猫使用形态攻速。英勇打击、顺劈斩、重殴、猛禽一击进入下一次攻击队列，执行时支付消耗；背刺、伏击、爪击经过共用命中与暴击判定。
- 法术命中考虑等级差、命中与天赋；护甲用于物理伤害，抗性用于对应魔法学派。抗性减伤先于吸收盾消耗。
- 法伤、治疗系数优先使用 `spell_bonus_data` 的显式数值，并沿技能等级链继承；显式零系数保留。缺失时使用原始读条、持续时间、跳数和范围类型的通用估算。低等级法术适用系数惩罚。
- 按学派分离装备法伤，冰霜伤害加成不会提升火焰伤害；独立汇总治疗、物理/法术命中、暴击、武器技能和防御技能。
- 敏捷暴击/闪避、智力法术暴击、近战/远程攻击强度按职业换算。形态护甲倍率作用于装备护甲，而不直接乘敏捷提供的护甲。

## 天赋与资源

现有九职业天赋解析继续基于技能族掩码、装备与形态条件匹配。冷却修正分别应用到技能恢复和类别恢复，震击的回响天赋因此保持共享冷却一致。

本轮增加或修正了：气定神闲与其他一次性施法状态的消费时点、飞行中法术的暴击增益快照、奥术专注节能施法的有效期、乱舞按挥击消耗层数、冲动在原有两秒能量节拍上翻倍、野性形态的排队攻击，以及技能暴击伤害天赋与公共攻击判定的连接。

## 尚未达到逐技能官方一致的部分

- 缺少精确系数的混合直伤/持续伤害法术仍有通用估算；每个例外需附数据证据，而非按技能描述猜测。
- 魔法部分抵抗仍有平均减伤近似，尚未完整重建逐次部分抵抗的概率档位。
- 角色面向通过当前攻击目标及位置推断；武器熟练度默认等级上限加装备/种族修正，没有熟练度练习过程。
- 宠物普通攻击、被控制单位的特有施法路径、全部触发概率/内部冷却及技能例外，尚未逐一完成同口径校准。
- 100 毫秒模拟步长与确定性事件处理未仿真原版网络延迟、客户端法术队列及各历史阶段的法术批处理行为。
- 控制递减、打断抵抗、施法击退、仇恨特殊规则、各类减伤/吸收/伤害转移的相互顺序、各首领脚本与所有天赋组合，仍需按具体场景补充官方实测证据和边界测试；不能从基础系统的覆盖推断这些例外均已完整实现。

后续扩展应区分“已验证”“参考实现”“估计”“未知”，把特例加入共同结算流程及相应测试，避免不同职业重新维护一套 GCD、命中或法伤公式。


## 战斗场景位置与目标显示

- 2.5D 场景以纵向压缩的地面投影显示真实坐标，微型人物/生物的脚底是位置基准；不做头像排版避让，允许聚集和遮挡，按脚底纵坐标排列前后层级。
- 原创矢量剪影区分职业装备及生物类型，精英、大型生物和首领有相对体型差异。这是原型外观，不是魔兽原版模型或精确模型碰撞尺寸。
- 所有单位、血条、目标线共享 180ms 的位置插值；新快照从当前显示位置继续移动。遭遇变化和减少动态效果时直接同步，模拟坐标不受插值影响。
- 施法期间连线优先使用施法目标，否则使用当前战斗目标；友方绿色，敌方红色。自身、死亡、移除或不存在的目标不绘制连线。范围按真实坐标投影为椭圆。
- 队员仅在已有走位动作中小幅偏转，尽量绕开 1.4 码内的队友；不会单独为了分散而移动或打断施法。走位仍遵守速度、定身、边界和战斗优先级。
