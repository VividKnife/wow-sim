# 暴风城监狱与地下城手册

2026-09-20 实现与验证记录。

## 可玩内容

暴风城监狱入口位于暴风城，五名存活成员均至少 15 级。路线包含 35 个遭遇、87 个普通怪生成位置、五名固定首领与一名 20% 概率出现的稀有首领。怪物组合在新冒险创建时确定，保存恢复不会重抽。支持自动推进、补给、复活、暂停、战利品处理与独立重置。

死亡矿井和监狱通过统一注册表运行，角色使用 `dungeonSaves[contentId]` 分别保存进度；返回沿用原 runId，重置只影响指定副本。两个副本共享每小时五个新实例的限制。旧的单副本存档结构已移除，不提供迁移。

六项副本任务及相关前后置共 18 条任务记录已接入，包括未寄出的信、监狱暴动、暴风城调查、袭击与乌瑞恩的图章。补充夜色镇、米奈希尔港、丹莫德等必要任务节点及 NPC、物品、音乐、地图标记和模型资源。袭击包含分阶段对话和真实战斗，支持失败重试、取消、断点恢复及防重复计数。

## 地下城页面

经典旧世 28 个地下城分区、254 个首领条目可查阅，支持地下城／区域／首领搜索、首领切换、掉落搜索、共享掉落开关及分页。物品展示品质、需求等级、装备属性和来源；没有可靠最终概率的条目不编造概率。黑石塔上层按十人标记，团队副本不在目录内。

目前可挑战的是死亡矿井与暴风城监狱，其余条目明确标记为仅供查阅。手册浏览不改变正在进行的冒险。资料经服务端 `clientContent` 静态边界发送，实时角色快照只携带运行视图，不重复传送大型图鉴。

- `npm test`：1069 项全部通过。
- `npm run typecheck`、`npm run check`、`npm --prefix apps/web run build` 通过。

- `node scripts/verify-stockades-combat.mjs`：配置好的 26 级五人队伍通过真实引擎完成 35/35 遭遇、93 次击杀、零死亡，模拟时间 43.67 分钟，六项副本任务均完成。60 级对照也完成。这是战斗夹具验证，不代表自然升级或任意装备均可通关。
- 浏览器验证：28 个目录条目、监狱六首领、稀有掉落中文名／21 级装备需求、物品搜索、查看其他副本时保持当前监狱冒险；无控制台错误。390×844 视口未出现横向溢出。

## 来源与边界

数据来自固定 Classic-DB 归档，可重跑导入脚本。来源、递归掉落、技能依赖与适配说明见 [导入记录](../research/import/stockades-journal.md)，中文名及图标证据位于 `docs/research/import/stockades-item-assets/`。

保留源数据的随机怪物组合：1000 个种子的审计中，348 个无法在一次清理中凑齐任务 387 的全部击杀种类，需要再次进入补齐，任务计数不会随副本重置丢失。无怒气／能量池的 NPC 按 AI 冷却与施法限制执行对应技能，是明确的模拟器适配；不宣称已经验证为官方服务器行为。二维朝向、路线组织亦为本项目适配。
