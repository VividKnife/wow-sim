# 专用背包与自动整理

随身库存仍只有一份物品堆叠列表。实际分袋布局由已装备的四个容器、基础 16 格行囊和堆叠顺序确定，不再把专用袋容量当成通用格数，也不另存可能失效的物品位置。

`bag-storage.js` 是容量和分袋规则的唯一入口。经典数据的 `BagFamily` 是枚举值，不能进行位掩码匹配；容器按 class/subclass 判断类型，因为多数专用袋自身的 `BagFamily` 为 0。

| 容器 | 可接收物品 |
| --- | --- |
| 通用背包 / 基础行囊 | 所有物品 |
| 箭袋 | 箭矢 |
| 弹药袋 | 子弹 |
| 灵魂袋 | 灵魂碎片 |
| 草药袋 | 草药家族物品 |
| 附魔袋 | 附魔家族物品，包括粉尘、精华、碎片、对应工具/配方和本项目附魔羊皮纸 |

物品优先占用匹配的专用袋，溢出后才放通用背包。不同家族不会混装；容器物品本身只能放在通用格。`sortBag` 合并属性相同的堆叠，并按分类、品质排序后分袋；锁定、绑定、附魔等属性不同的堆叠不混合。重读存档按同样规则重建布局。

- 商店购买、拍卖购买、制造、拾取、角色转移、邮件领取、银行取出和后台材料归还统一校验匹配容量。拒绝交易不扣钱、不丢物品；可部分拾取的剩余物品保留待拾取状态。
- 装备背包可指定 0—3 栏位；未指定时优先空位，满栏时选择可安全替换的最小背包。更换类型或缩小容量可以进行，但最终布局必须合法。卸下同样预先校验，换下的容器回到通用背包。
- 角色界面分袋显示物品、类型和使用量，支持按袋筛选和卸下；总空位和通用空位分开显示。野外狩猎/副本继续条件使用通用空位，不能被空箭袋误导。

验证：`node --test packages/game-domain/test/specialty-bags.test.ts`，并运行物品转移、邮件、制造、拾取、常驻实例库存与弹药补给回归。
