# 常驻实例、离线与回收

进入选定角色时创建或恢复实例，角色选择页本身不创建实例；战斗外技能和增益也由服务器处理。

- 在线且没有需要演化的状态：保留内存实例，调度器休眠；有效命令或规则期限唤醒。
- 页面关闭、网络断开或浏览器退出：不向浏览器转交执行权，不依赖 unload 上传。仍在进行的活动使用相同内核继续推进，默认离线上限两小时。后台标签仍有有效连接时视为在线；关闭一个标签不会使其他标签或设备离线。
- 活动结束或暂停狩猎、没有战斗/恢复/活动期限/拾取/竞拍/限时任务等待处理边界，且无人访问默认 60 秒：提交检查点后释放 worker 实例和租约。下一次访问从持久状态恢复；原离线额度不会重置。计时从检查点观察到空闲开始，检查点节奏可能延后回收。
- 增益到期、资源恢复等在提前卸载后按原内核补算，受原离线上限约束；不使用平均收益替代规则。
- 共享副本以最早达到离线上限的真人冻结规则，页面显示原因；仍有成员访问时保留 owner，避免反复创建。全部离线额度到期或满足无人访问的空闲回收条件才卸载。不自动踢人或改变控制权限。
- 手动暂停保持暂停。经济期限与战斗时钟分开。提交失败时停止权威推进，不丢弃尚未确认的奖励；重新接入校验 epoch 和基线。进程崩溃后按访问恢复，未提交画面允许回退。

配置：`SIMULATION_IDLE_RETIRE_MS=60000`，允许 100–3600000 毫秒；离线上限为 `GAME_OFFLINE_LIMIT_MS=7200000`。WS 心跳判断断线有延迟，因此回收不是页面关闭后精确第 60 秒发生。

2026-10-01 验证：空闲策略、共享离线期限、重连、回收竞争、提交失败、真实 Worker 唤醒及 HTTP 权威共 21 项通过。之前服务器模拟完整回归 274 项通过；这些结果不代表目标机器并发容量。
