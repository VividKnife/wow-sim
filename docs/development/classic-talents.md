# 经典天赋界面

角色的「天赋」页与竞技场 PvP 配置共用 `apps/web/app/talent-tree.tsx`。每棵树保留源数据的四列、七层坐标，使用本地经典天赋背景；法师的三个背景按天赋树 ID 对应。

- 鼠标悬停或键盘聚焦查看等级说明；点击图标或 Enter / Space 投入一点。
- 未投入图标灰度显示；绿边表示可投入或已有等级，金边表示点满，灰边表示未解锁。
- 箭头表示前置关系；前置满足时变绿，目标点满时变金。
- 触屏先点图标查看详情，再按「投入 1 点」。窄屏详情固定于底部，可关闭或按 Escape 收起。
- 冒险加点立即提交现有 `talent` 命令，由服务端验证。洗点继续使用职业训练师、费用和 `resetTalents` 规则。
- PvP 中右键、Delete / Backspace 或「退还 1 点」减点，继续校验层级及前置依赖。移除主动天赋同步移除相关技能规则；修改仍需保存 PvP 配置。
- 未解锁和满级节点仍可聚焦查看说明。具体加点／退点按钮保持禁用态，提交期间防止重复请求。

背景原图的四块纹理合计 320 × 384，但有效画幅仅 299 × 331；CSS 在拼接时排除右侧、底部透明留白。

## 本地预览与验证

运行 `npm run demo:classic-ui`，打开 `http://127.0.0.1:5198/talents.html`。预览使用真实引擎数据，支持九职业、9 级无点数、示例加点和 PvP 配置，不访问用户存档。

`apps/web/test/talent-tree-render.test.mjs` 覆盖 27 棵树的节点、前置连线、本地背景与等级显示；领域层现有测试继续验证天赋合法性和 PvP 保存行为。
