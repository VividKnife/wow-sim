# 熔火之心：25人地图副本

主游戏「地下城」提供公会团和金团两个入口，均使用与5人本相同的地图组件。包含十名首领、十五组小怪、分支路线、目的地推进、暂停、全清规划和检查点。底图使用暴雪客户端原版熔火之心插图，首领和怪群标记按房间叠加，素材来源及校验见[原版地图接入](../research/import/dungeon-maps.md)；首领机制和小怪配置为本作改编，掉落使用固定版本 ClassicDB 1.12 表，不是原版40人的完整数值复刻。

## 游玩流程

创建页可选择60级团本体验法师，或使用五名存活的60级核心角色。公会补齐20名队员；金团先公告规则、招募NPC并锁定名单。全团至少2坦克、5治疗。

点击地图上的怪物群或首领，查看组成、机制、掉落及沿途路线，再选择推进。不能越过未清理的沿途遭遇，每场胜利保存节点，3秒后继续下一场。选择的目的地清理完成后停止。全清按地图编排依次完成所有区域。

有队员倒下、团灭、撤退或未领取战利品时停止推进。在营地休整10秒可复活和恢复全团，随后从地图继续。每次开战补足资源；首领之间可以调整战术和装备。退出、服务重启和重新进入保留首领、小怪与当前位置。

前八名首领允许按分支选择顺序。全部击败后熄灭符文并解锁管理者，击败管理者后解锁炎魔之王。完成十首领后可以重开练习，清空地图进度但保留本周奖励领取资格。

## 奖励与持久化

公会团与金团共用 ClassicDB 1.12 原版掉落图，包含十首领（管理者使用炎魔宝箱）、当前路线小怪、引用掉落组、材料、配方、T1、炎魔 T2 腿及传说任务材料。没有按玩家职业筛选的保底，也没有固定三件或30%特殊掉落。公会团每周首次清理节点领取实际掉落；金团按实际数量后台拍卖，任务条件掉落直接发给符合条件的玩家。拍卖不阻挡路线，非装备拍品不会进入NPC装备槽。详情见 [MC 掉落来源](../research/import/molten-core-loot.md)。

周一00:00 UTC重新进入时重置公会地图和奖励资格。进行中的实例保留进入时周资格。重复请求和练习击杀不重复领取奖励。实例仍只租用五名核心角色；20名公会／金团NPC保存在实例内。

## 实现与验证

- `molten-core-content.js`：首领、小怪模板、地图节点、路径与解锁条件。
- `molten-core-navigation.js`：沿途战斗、停止、清理检查点和继续推进。
- `molten-core-battle.js`、`molten-core-encounter.js`、`molten-core-mechanics.js`：遭遇构造、支援与十首领机制。
- `guild-raid.js`、`gold-raid.js`：各模式的奖励、经济、名单与视图。
- `dungeon-map.tsx`：5人本、公会团和金团共用地图交互。
- `molten-core-route.test.ts`：连通性、十五组小怪、解锁、暂停、JSON恢复、全路线结算、周资格及25场真实战斗。

### 本轮验收（2026-09-22）

102项定向测试通过：29项地图／真实遭遇测试（含全部十首领、十五怪群与跨模式奖励隔离）、12项公会团／金团服务测试、29项Demo／战斗回放与视图测试、32项5人本地图与界面规范回归。真实战斗采用种子60325和基础25人阵容；此结果验证可完成性，不代表所有配装或随机种子的最终平衡。
