# 60级单人工会团本

主游戏「地下城」顶部可以进入熔火之心25人公会远征。当前完整开放鲁西弗隆和玛格曼达两名首领；并非原版十首领全本。旧的5189端口页面保留为独立实验Demo，正式角色从5173端口主游戏进入。

## 创建与游玩

角色创建页选择「等级60 · 团本体验 · 法师」，填写角色名。服务端在同一事务中创建一名60级人类法师、四名60级长期伙伴、各自独立装备资产和五人出战名册；提供蓝装、技能、预设天赋、背包及100金币。该起点与已有20级测试直升一样，是本开发阶段的体验入口。

进入地下城后集结公会。五名核心队员必须均为存活的60级角色；公会补齐固定四支五人队。默认全团2坦、5治疗、18输出。队员跨小队治疗与支援，公会分组不限制战斗目标。首领开战前检查至少2坦、5治疗；核心队职业与策略仍可在原有角色系统配置。

1. 配置清护卫、驱散、宁神、防恐与撤离火区五项战术。
2. 挑战鲁西弗隆，处理两名护卫、末日和诅咒。击败后解锁玛格曼达。
3. 拾取掉落，可以在角色页装备或通过现有同账号装备分享流程配给核心队。
4. 团灭后营地休整10秒，恢复全团生命、法力、技能冷却和弹药，再次挑战。每场开战亦补足资源。休整不收费。
5. 可离开保存进度，后续重返继续。两首领全通后可以练习重开。

首领每周首次击败提供1件优先适合团长的紫装。采用本作专属装备和奖励池，不冒充原版掉落。周重置在周一00:00 UTC（新加坡周一08:00），重新进入时刷新本周路线与资格。进行中的实例沿用进入时的周资格；练习重开不重新发放本周奖励。

## 服务端与资产边界

- `rules/guild-raid.js` 定义进入、战术、首领解锁、恢复、周资格、奖励和公开视图。
- `rules/molten-core-battle.js` 与 `rules/molten-core-encounter.js` 为正式玩法和Demo共用的遭遇构造与机制；伤害、仇恨、技能资源、驱散和移动复用原有战斗引擎。
- `molten-core-roster.ts` 为公会成员与60级体验起点提供合法预设；`raid-ready.ts` 把核心五人持久化为真正拥有的角色。
- `rules/raid-rewards.js` 为普通物品目录提供12件本作紫装，拥有正常唯一实例、绑定、背包和装备规则。
- 实例容量25，`Instance.roster`记录5个真正拥有的角色，使用现有角色租约。20个公会单位仅存在于权威实例模拟，不创建玩家角色、钱包或可转移装备资产。
- 公会进度和周奖励领取标记保存在团长规则状态，物品则通过现有 `persistAssets` 独立持久化。实例、领取资格、战利品和经济流水在同一事务内结算；相同请求和重复推进不重复领奖。
- 当前为单账号公会玩法，禁止跨账号加入和佣兵合同。战斗采用服务器实时结算，不提供Demo暂停／加速。沿用现有离线时限、工作线程租约与重启检查点。
- 前端 `guild-raid.tsx` 接入地下城页；战斗使用原有HD-2D渲染，加入熔火环境、机制倒计时与实际熔岩火区。

首领机制来源与25人改编范围见 [Demo说明](molten-core-demo.md)。没有新增原版完整小怪路线或其他八名首领。

## 本机运行

```powershell
docker compose up -d postgres
npm run data:compile
npm run game:server
# 另一终端
npm run game:worker
# 另一终端
npm --prefix apps/web run dev
```

访问 <http://localhost:5173>。API、worker和Web的数据库地址及共享密钥应一致，细节见[运行说明](game-runtime.md)。已创建的本机试玩账号凭据位于忽略提交的 `.cache/molten-core-play-account.txt`。不要提交或部署此文件。

## 验证

`packages/game-domain/test/guild-raid.test.ts`覆盖60级核心队创建与幂等、合法资产、五个真实角色租约和20个公会单位、25人容量、首领顺序、战斗中战术锁定、放弃／休整、服务对象重建后的连续双首领实战、紫装拾取装备、离开重返和重复击杀不重复发奖。另验证跨周资格刷新、禁止加入与佣兵合同，以及紧急脱离后释放公会营地、保留核心队并可重新进入。

与存档、账号权限、服务命令、离线恢复及快照投影共同运行的54项测试通过；原有职业战斗、资源规则、队友战斗和共用Demo的65项测试通过。浏览器使用独立验收角色进行真实PostgreSQL实例、首领战斗和掉落操作，玩家交付角色保留初始进度。

最终补充的跨周与紧急脱离测试，以及原有9项脱离卡死回归通过。根目录与Web类型检查、JavaScript语法及内容清单一致性检查通过。浏览器验收两名首领完整击杀、掉落拾取、退出保存、390px手机营地布局和桌面营地；交付角色刷新后保持0/2进度、25人和完整资源。
