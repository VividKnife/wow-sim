# 脱离卡死

主界面底部的「脱离卡死」可处理当前所选角色所属的副本、个人活动和后台订单。点击后显示影响范围，再点击「结束活动并脱离」执行。

允许使用的条件：活动内容版本已失效、下次结算时间逾期至少 60 秒，或活动已经失败。正常活动会被服务端拒绝；更换角色不能操作其他账号的角色。旧版本失效可立即使用，不需要等待 worker。

- 副本：取消当前战斗和活动，结束旧运行实例并解除占用，佣兵合约结束。死亡矿井成员返回月溪镇，已提交的路线、击杀、机关和统计进度保存到原队长的副本存档。原队长重新进入后从原进度继续，未击败的敌人按原始生成状态重新挑战；自动推进暂停。进度不复制给其他成员，避免一个共享进度分裂成多份。取消点火时退回已经消耗的火药，保留尚未开启的机关。任一参与者都可处理已卡住的共享实例，其他账号会收到版本更新后的状态。
- 个人活动：取消当前活动并解除所有参战成员占用，旅行停留在已保存的位置。
- 制造和采集：取消订单，制造预留材料退还付款角色；工具保留原 UID、绑定、耐久等属性。满包时退款进入待领取物品。
- 恢复角色：清除当前战斗、施法、持续伤害和恢复动作；倒下成员恢复 50% 生命与法力。保留已经持久化的成长、金币、背包和待领取物品，不发放未结算的战斗/活动收益。

操作在一个事务中完成，命令收据防止重复执行。它直接使用已提交的角色和资产，不调用旧活动的推进逻辑；战斗预计算作废，副本 worker 租约失效，防止取消后重新写回战斗结果。

这是已有异常活动的恢复入口，不替代内容更新时的发布管理。游戏 API 必须可用；仅靠前端无法恢复离线服务器。

验证：`node --test packages/game-domain/test/unstuck.test.ts`。
