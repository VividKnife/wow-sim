# 脱离卡死

主界面底部的「脱离卡死」可处理当前所选角色所属的副本、个人活动和后台订单。点击后显示影响范围，再点击「结束活动并脱离」执行。

玩家可随时主动使用，不检查活动版本、失败状态或逾期时间。正常战斗、旅行、制造和采集都可以立即取消；没有活动时也会清理所选角色的残留战斗/施法状态。更换角色不能操作其他账号的角色。操作不依赖 worker，也不会先执行可能已经损坏的重连补算。

- 副本：取消当前战斗和活动，结束旧运行实例并解除占用，佣兵合约结束。死亡矿井成员返回月溪镇，已提交的路线、击杀、机关和统计进度保存到原队长的副本存档。原队长重新进入后从原进度继续，未击败的敌人按原始生成状态重新挑战；自动推进暂停。进度不复制给其他成员，避免一个共享进度分裂成多份。取消点火时退回已经消耗的火药，保留尚未开启的机关。任一参与者都可结束当前共享实例，其他账号会收到版本更新后的状态。
- 个人活动：取消当前活动并解除所有参战成员占用，旅行停留在已保存的位置。
- 制造和采集：取消订单，制造预留材料退还付款角色；工具保留原 UID、绑定、耐久等属性。满包时退款进入待领取物品。
- 恢复角色：清除当前战斗、施法、持续伤害和恢复动作；倒下成员恢复 50% 生命与法力。保留已经持久化的成长、金币、背包和待领取物品，不发放未结算的战斗/活动收益。

操作在一个事务中完成，命令收据防止重复执行。它直接使用已提交的角色和资产，不调用旧活动的推进逻辑；战斗预计算作废，副本 worker 租约失效，防止取消后重新写回战斗结果。

活动记录缺失但执行租约仍存在时，清理残留租约、回放和副本 worker 占用；有已提交的制造预留时照常退还。没有活动或重复点击不会被“未卡住”条件拒绝。

这是主动恢复入口，不替代内容更新时的发布管理。游戏 API 与数据库必须可用；身份校验和资产事务保护仍然生效，不能承诺网络或数据库故障时一定成功。

验证：`node --test packages/game-domain/test/unstuck.test.ts`。
