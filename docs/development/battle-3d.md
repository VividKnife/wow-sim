# 原版 3D 战斗与人物外观

野外、五人本、MC、竞技场共用 `BattleHD2D` 的 Three.js / React Three Fiber 场景。内部模块名保留，产品界面显示「3D」。模拟仍负责位置、施法、伤害、死亡和阶段时间；画面只读取投影，不改变战斗结果。

## 人物外观

- 8 个经典种族 × 男女体型，共 16 个原版身体、骨骼与动作文件。
- 覆盖 80 种合法种族／性别／职业组合；每种有初始服装和 T1，共 160 个外观预设。
- 60 级自动使用对应职业八件 T1。低等级使用职业初始服装。保留种族和性别。
- 这是职业外观预设，背包中的实际装备不驱动换装。武器目前沿用职业基础武器；T1 本身没有武器。
- 身体网格按原版 geoset 选择衣袖、手套、长袍和靴型；合成衣服贴图以无损 WebP 保存。头盔、左右肩甲和武器挂在原版骨骼节点上，随动作移动。
- 德鲁伊变形、变羊优先于套装；效果结束后恢复人物预设。

2026-09-22 的人物资源实测（不含 NPC、生物、场景、音频和运行库）：

|资源|数量|磁盘体积|
|---|---:|---:|
|共用身体与动作 GLB|16|24.59 MiB|
|去重后的装备 GLB|103|4.73 MiB|
|去重后的皮肤 WebP|166|33.18 MiB|
|合计|285|62.50 MiB|

已移除旧的 85 个重复 GLB（116.28 MiB）。人物 GLB、皮肤和装备按出场外观加载，同 URL 由加载器缓存；不预下载所有人物。抽查人类男性战士、牛头人女性萨满、侏儒男性法师的完整 T1 首次加载分别约 1.72、2.13、1.99 MiB。这里是未压缩 HTTP 传输前的文件大小，不是 GPU 显存占用。

完整逐件换装可以沿用这一结构，但仍需导入物品显示映射、按种族适配装备部件、处理双持／盾牌／远程武器、组合贴图缓存与逐件视觉校验。当前没有打包全物品库。

## 动作、镜头与音效

原版 M2 顶点权重、骨骼、逆绑定矩阵和动画轨道转为 GLB。每个角色克隆独立骨骼并拥有独立 AnimationMixer，共用几何与贴图。战斗事件控制待机、移动、攻击、施法、受击、死亡；MC 阶段投影控制拉格纳罗斯下潜／现身及管理者投降状态。投降使用原版中立站姿。

透视镜头默认自动取景，拖动旋转、滚轮缩放、右键平移；「恢复自动镜头」回到跟随。低特效模式关闭后处理并限制刷新，页面隐藏时停止渲染。

所有战斗共用本地 OGG 音效播放器。用户开启音效后，依据施法、伤害、治疗等事件播放，支持音量调节；隐藏、关闭或结束战斗会停止声音。重复事件、过期事件和拥挤声道不会排队补播。这里未实现每个 NPC 的专属语音与完整环境音。

## 资源来源与重建

原画及原版模型属于 Blizzard Entertainment；本地转换源为 Wowhead Classic 模型 CDN。人物 manifest 保存物品来源页及摘要，模型记录源文件摘要。装备物品展示 ID 来自 Classic 物品页，而非假定所有数据库版本的显示 ID 相同。

```powershell
python scripts/import-molten-core-models.py
python scripts/import-classic-battle-models.py
python scripts/import-classic-character-appearances.py
npm run data:compile
$env:PREVIEW_PORT='5191'
node apps/web/scripts/serve-dungeon-preview.mjs
```

Python 需要 Pillow。导入缓存位于 `.cache/molten-core-models`；人物导入使用检查点，可中断续跑。需要重新转换人物时，清除该目录下的 `character-appearances-progress.json` 后重跑（源下载缓存可保留）。替换源数据后应重新生成数据 manifest。

原版格式解析参考 [wow.export](https://github.com/Kruithne/wow.export) 的公开 M2 / SKIN / SKEL 格式实现；没有打包 Wowhead 网页模型查看器。当前转换保留基础贴图材质和骨骼动作，未完整复刻 M2 粒子发射器、缎带及全部多层着色器，不能视为原客户端渲染器的完整复刻。

## 验证

- `/character-models.html`：种族、职业、性别、初始服装／T1、六种动作。
- `/battle-3d.html`：野外、五人本、MC、竞技场独立试玩，不连接账号和存档。
- `/molten-core-models.html`：MC 首领、小怪、随从和召唤物。
- 人物 119 个 GLB 经 Khronos glTF Validator 检查，0 错误、0 警告。
- `character-models.test.mjs` 检查 80 种组合、60 级切换、资源摘要、本地皮肤、骨骼挂点、变形覆盖与资源体积。
- `molten-core-models.test.mjs` 检查全部 MC 模型、独立骨骼和动画采样不产生非有限顶点。
- 本次人物、MC 模型、音效、竞技场投影和镜头相关 57 项测试通过；Web TypeScript 与修改的核心渲染／人物预览文件 ESLint 检查通过。
- 额外的 MC 实战回归中，24 / 25 场遭遇通过；`real combat: baron-geddon` 未通过：默认队伍于 190 秒团灭，首领剩余 2,427 生命。该项属于当前工作区的战斗平衡结果，人物外观实现不修改伤害、装备属性或首领数值。

预览服务器禁用文件监听，避免批量资源导入触发 Windows 文件监听器错误。修改预览源码后重启服务器；正式 Next 开发服务器不受此设置影响。Tailwind 显式扫描界面源码目录，避免把大型二进制资源库当成样式来源。
