# 角色属性面板

装备页按基本、近战、远程、法术、防御、抗性六组显示属性。
`character-attributes.js` 从战斗使用的 `stats()`、装备与有效光环生成展示数据，完整快照、战斗快照及回放中的所选角色均携带该数据，前端不另算战斗公式。

- 命中显示加成，不代表最终命中率；武器技能、目标等级及双持惩罚仍由攻击表结算。
- 当前规则使用武器技能，没有独立精准属性，因此精准标为“不适用”。
- 防御概率以同级、正面、可防御为基准；计算光环与防御技能修正，不承诺施法、被控制或背向敌人时仍能防御。
- 格挡需要未损坏盾牌，格挡值复用战斗中的盾牌、力量和天赋计算口径。
- 法术命中和暴击为通用值；学派法强为通用法强加该学派加成，特定技能与目标修正仍在施法时结算。
- 未装备副手武器或远程武器时，相应技能显示“—”；猫、熊形态使用等级对应的近战技能。

验证：`node --test apps/web/test/character-attributes.test.mjs apps/web/test/classes60-active-stats.test.mjs`。
