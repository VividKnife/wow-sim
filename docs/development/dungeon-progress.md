# 副本离开与返回

死亡矿井的活动进度由实例 `simulation.dungeon` 持有。队长所属账号离开时，服务器先执行规则层 `leaveDungeon`，将完整路线写入队长角色的 `rules.dungeonSave`，结算成员与资产，再释放角色占用。离开实例和离开副本两个命令使用同一保存流程。

在副本外整理背包、保存角色或重启服务不会删除 `dungeonSave`。返回时按角色当前装备、背包和队伍建立执行实例，恢复保存的路线，并沿用原 `runId`，保留怪物生成结果、击杀、交互和累计战斗统计。执行实例 ID 可以变化；副本冒险的 `runId` 不变。

入场时立即持久化新副本计数并消费保存的进度。返回已有冒险不占新的每小时入场次数；只有明确执行 `resetDungeon` 才删除保存的路线，下次进入重新生成副本。进度保存归队长角色所有，不给退出的跨账号访客复制一份独立进度。

回归：`node --test packages/game-domain/test/dungeon-progress.test.ts`，覆盖两种离开命令、背包修改、服务重建、路线及统计保留、主动重置与每小时新副本数量限制。
