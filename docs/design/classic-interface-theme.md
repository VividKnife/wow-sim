# 经典界面主题

共享主题位于 `apps/web/app/classic-controls.css`，由 `globals.css` 引入，覆盖经典界面、网页界面以及独立预览。

- 面板采用暗色石质底、金属边框和内凹内容区；标题使用金色宋楷衬线字体，说明与数值使用易读的系统字体。
- `Button` 默认操作与 `.classic-button` 使用红色浮雕按钮；outline / secondary 使用深色金属按钮，ghost / link 保持轻量。禁用、按下、悬停与键盘焦点都提供独立反馈。
- 标签页、GameSelect、文本输入框、原生复选框、Radix Checkbox、滑块、关闭按钮与弹出菜单共享金属边框与金色高亮。
- `--wow-*` 变量定义材质与颜色；新控件优先使用这些变量，避免重新引入青灰色通用应用样式。物品品质、生命、法力、职业与危险提示仍保留语义颜色。
- NPC 任务对话继续使用独立的深棕任务阅读面板；地图、技能图标及装备槽保留现有图像与比例。

设置使用 Radix Tabs 分为声音、画面、游戏和账号。桌面为侧栏分类，手机为单行分类；分类可用方向键切换。选项沿用原有保存机制，音乐或音效关闭时对应音量滑块禁用。自动拾取未启用时，灰色物品过滤保持禁用。

独立验证：运行 `npm run demo:classic-ui` 后打开 `/classic-interface.html`。该预览使用真实设置、NPC 与通用控件，角色命令仅作用于内存中的预览角色；本机声音和画面偏好仍使用真实的本地偏好存储。
