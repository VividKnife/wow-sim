# 25人团本开荒体验

## 目标与边界

玩家掌控自己的五人核心队，承担25人团长职责。公会团提供稳定成员，金团增加招募、执行水平、消费意愿与分金决策。两种模式共享首领机制和指挥工具，入口统一在独立「团本」标签，五人地下城留在「地下城」。

开荒的进步应来自理解机制、安排职责、识别执行问题、调整方案。不能把所有选项都做成常开增益，也不采用“团灭几次后加属性”的隐性保送。当前实现是本作的25人改编，不是经典服数值复刻。

## 一轮尝试

1. 选目标首领，阅读机制摘要，检查当前阵容实际拥有的技能。
2. 发布该首领的战前指挥：主副坦、默认集火、站位、火区纪律、驱散与关键技能负责人。
3. 自动清理沿途小怪；抵达首领前停止推进。玩家检查方案、领取未拾取装备、休整，然后确认开怪。
4. 开战固定本次方案。战中可以改变集火目标、下达预留技能口令；不能回到营地临时换负责人。
5. 战斗结束生成本次复盘。查看首领剩余血量、首个死亡、治疗余蓝、机制失误、实际使用与未使用的预留技能。
6. 修改一两项安排，重新发布、复活再战。保留已清首领和小怪进度；记录尝试时的方案，避免后改方案覆盖历史证据。

未发布时提供合理建议方案，让玩家能先试一次；不额外增加强制教程。方案按首领分别保存，避免把古雷曼格的集火方案误用到议会。

## 战前决策及真实代价

| 决策 | 实际作用 | 取舍与失败信号 |
| --- | --- | --- |
| 主坦、副坦 | 决定开场首领与小怪的仇恨目标、后续坦克目标分工 | 盾墙必须交给实际主坦；坦克先倒时检查分工、技能和装备 |
| 先清小怪 / 集中首领 | 改变输出单位的实际目标 | 清掉治疗小怪能缩短战斗；古雷曼格应压首领，盲目清犬会浪费输出 |
| 分散 / 紧凑 | 改变开场成员空间分布 | 分散减少范围波及，紧凑更利于治疗覆盖；不是永久范围免伤增益 |
| 提前撤离 / 贪读条 | 火区预警期间是否取消读条移动 | 提前移动损失输出，贪读条可能来不及撤出；NPC水平仍影响执行 |
| 专人 / 全员驱散 | 专人模式只由名单成员处理；两名驱散者优先分管不同小队，随后互相补位 | 专人保留其他人的治疗与输出时间；全员处理更稳，但占用更多施法时间和法力 |
| 宁神、防恐负责人 | 仅指定名单中的可用成员处理；前者解除实际狂暴光环，后者为实际主坦施加结界 | 未学技能不能录入。死亡、控制、距离、资源和冷却都会造成空档 |

不再向玩家展示五个常开战术勾选框。现有机制开关保留作底层机制执行配置和独立沙盘测试使用；正式团本由指挥方案决定分工。

## 关键技能与团长口令

预留的技能退出普通AI自行施放流程，交由团长安排执行。执行复用现有职业技能效果、法力与冷却系统，不凭空发放团长技能。

| 技能 | 自动安排 | 玩家下令 | 限制与代价 |
| --- | --- | --- | --- |
| 盾墙 | 主坦低于45%；玛格曼达可选狂暴时，或恐慌前2秒 | 提前覆盖预期伤害窗口 | 主坦必须是学会盾墙、持盾且姿态正确的战士；遵守技能冷却 |
| 圣疗术 | 主坦低于25% | 应对坦克即将死亡 | 圣骑士必须在施法距离内；施放后耗尽自己的法力 |
| 激活 | 法力最低的治疗低于25% | 在持续高压前安排回蓝 | 必须有学会激活的成员；目标需存活且在距离内 |
| 切换集火 | 按战前方案开始 | 在小怪与首领之间切换，5秒内不能反复切换 | 会改变真实攻击目标；炎魔下潜时仍必须攻击可攻击的小怪 |

救急技能会取消负责人的当前读条，体现抢救代价。公共冷却、控制、死亡、距离与资源限制会在按钮上显示。没有该职业或技能时明确显示缺口，不能靠团长按钮绕过招募。

战斗窗口只显示一条口令栏；详细分工与复盘留在营地。关闭观察窗口不停止战斗，也不取消已发布的自动安排。

## 复盘原则

复盘报告应先给证据，再给可执行的改动。

- 末日爆炸：提示补足驱散负责人或改全员协助，并说明这会牺牲治疗、输出时间。
- 火区伤害：提示提前撤离、分散；金团可考虑执行更稳定的成员。
- 首个死亡为坦克：检查盾墙和圣疗的条件与时机，避免同一血线一并交完。
- 治疗平均法力不足20%：检查回蓝与无效长战斗，尤其是仍存活的治疗小怪。
- 达到狂暴时限：检查集火与伤害统计，不能只给“装备不够”的结论。
- 未使用的预留技能：仅作为检查线索，可能是没有达到条件，不能自动判为失误。

「根据上次复盘调整草案」会把火区纪律、驱散范围和关键技能触发方式调整成保守方案，玩家核对后再发布。报告中的建议是基于观测的解释，不宣称单次记录能证明唯一死因。

与同一首领上一场比较剩余血量；跨首领不做虚假的进步对比。当前保留最近20次尝试，记录方案、执行口令和关键计数。

## 后续迭代顺序

1. 先用试玩记录验证上述选择能产生可解释的结果，关注团灭后是否改方案、再战是否提高存活和机制完成率。
2. 扩展有现成机制支撑的打断轮换、逐只小怪标记、治疗分区与减伤时间轴，避免一口气增加十几个无效按钮。
3. 增加金团团员跨团记忆与执行评价，帮助团长判断招募取舍；不能仅以DPS决定分金资格。
4. 有足够开荒数据后再考虑可选英雄难度、限时挑战或联机合作，不以强制真人组队阻断单人内容。

## 本轮验证与试玩

- 指挥规则覆盖角色资格、战斗锁定、按首领保存、真实技能效果与资源、手动口令、恐慌时间窗、集火目标、驱散缺口、躲火纪律、首领前停步及复盘持久化。
- 公会团与金团原有回归通过；实战覆盖鲁西弗隆、玛格曼达、古雷曼格、埃克索图斯与拉格纳罗斯（含下潜阶段）。
- 本地浏览器实测发布指挥、沿途清怪后停步、转火与盾墙口令、主动撤退复盘、全团休整、退出保存，以及重新进入后实际击败鲁西弗隆并领取奖励。桌面和390px窄屏检查通过。
- 修复本地战斗撤退后残留执行权阻止休整的问题，并验证过期页面指令仍被拒绝。没有掉落时不再自动弹出空战利品窗口。
- 主动撤退与自然团灭在复盘标题中区分；撤退结算人数不作为死因证据。

目前是本地开发版本；尚需玩家试玩来调节指挥负担、触发阈值和各首领的开荒难度。规则测试验证了选择确实影响机制，不代表所有阵容与每个选择已经完成胜率平衡。
