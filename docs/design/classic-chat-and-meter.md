# 经典聊天与记录窗口

## 视觉与布局

按原版极简聊天框处理：消息直接叠在场景上，上方仅一排半透明标签「世界 / 队伍 / 综合 / 战斗详情 / 战报」。取消独立标题栏、整块面板边框、模糊背景、消息卡片、重复频道栏、常驻连接状态、综合筛选和活动摘要。淡色标签和黑色文字阴影保证在场景上可读。

正文使用紧凑连续行，没有时间列、分类徽章或分隔线。聊天格式为 `[频道] [玩家名]：正文`。玩家名称根据消息的 `classId` 使用职业色，与经典 HUD 共用 `lib/class-colors.ts`；自己的发言也遵循职业色，不用另一种身份色覆盖。世界正文为浅粉色、队伍为淡紫色，综合记录的拾取为绿色、经验为紫色、任务为黄色。完整时间可悬停查看，不占阅读空间。

世界和队伍标签下保留一条轻量输入框。招募消息默认也是普通文本，等级、职责缺口和加入操作收在「招募详情」中。网页社交页面复用消息行为和职业色，但保留适合独立页面的消息排版。

桌面窗口位于快捷技能上方，避免挡住施法按钮。工具按钮在悬停或键盘聚焦时突出显示；支持拖动、方向键微调、Home 或双击复位，以及设置中的统一位置重置。

手机竖屏（≤800px）和小尺寸横屏（宽≤1000px、高≤500px）默认收起。展开后仍是半透明标签和文字，不加遮罩，保留场景操作。输入字号 16px，支持软键盘 VisualViewport 调整；窄屏隐藏拖动柄，统计和收起入口放在标签右侧。Escape 收起后将焦点返回聊天入口。

## 消息与输入

- 世界和队伍草稿独立保留，队伍草稿绑定队伍 ID。标签切换或收起不清空，刷新不保留。
- Enter 发送，中文输入法组词期间不提交；发送失败保留草稿。成功后仅清空本次原草稿，不覆盖发送期间新输入的文字。
- 未连接或未组队时禁用相应输入；连接异常显示简短状态。
- 阅读历史时新消息不抢滚动位置，提供“新消息”入口；回到底部后恢复跟随。
- 招募加入按钮按角色等级、职业支持的职责和目标队伍过滤，最终条件仍由服务端校验。
- 职业 ID 在服务端从发言者角色读取，覆盖世界消息、队伍消息和招募公告，不接受客户端伪造职业。

综合记录保留最近 100 条非战斗事件；战斗详情单独展示最近 100 条战斗事件。记录按时间从旧到新排列，未知事件保留显示。战报继续复用 `JourneyLog`，统计继续复用 `LiveDamageMeter`。

2026-10-01：

- Chromium 验证 1440×900、1024×768、390×844、320×640、844×390：窗口边界、横向溢出、长消息、招募展开、频道切换、收起焦点、统计入口和键盘定位。
- 验证草稿隔离、中文组词、发送失败/成功、历史滚动与新消息、未组队输入禁用，以及法师和战士姓名的实际渲染颜色。
- 模拟 VisualViewport 高度 320px，检查窗口和发送按钮均在可视区域；未使用真机验证系统键盘和触摸操作。
- 社交领域与 HTTP 共 12 项测试通过，包括世界/队伍/招募职业 ID，以及客户端伪造职业不会改变消息身份。
- 网页 TypeScript、相关 ESLint、生产构建通过。构建保留已有静态资源运行时解析和大包提示。
