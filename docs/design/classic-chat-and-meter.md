# Classic 主页频道与完整统计

主页使用浏览器内容区的完整高度（100dvh），移除下方重复的小队、统计、旅途记录和工具条。保留左上方队伍状态；设置中保留角色与后台活动、网页 UI 切换入口。音乐控制器持续挂载。

左下角用暗色半透明背景、金色细边和频道页签，综合频道保留操作反馈与原有活动/恢复信息，并展示最近日志；战报频道复用 JourneyLog，支持历史战斗详情。频道内容独立滚动，Radix Tabs 支持键盘切换。

右下角复用 DamageMeter，保留当前/上一场与副本累计范围、成员技能伤害、宠物伤害、占比、命中与暴击及折叠。列表单独滚动，不截掉总计。窄屏通过频道栏“伤害统计”进入完整窗口。手机指挥战斗中频道默认收起，避免遮住指挥栏。

修正的问题：
- 旧账号栏内联 display 覆盖隐藏规则，造成额外 30px 页面高度：修正 Classic 隐藏优先级。
- 手机角色名牌与频道重叠：隐藏场景重复名牌，顶部角色信息保留。
- 1024px 窗口中第五名队员被聊天框覆盖：限制队伍框架高度并独立滚动。
- 统计展开/较矮窗口中底部总计可能被截断：统计改为有界 flex 容器，仅成员列表伸缩滚动。

实际验证：
- 1440×900、1024×768 主页，390×844 主页，360×740 完整统计；页面宽高无多余滚动。
- 综合 → 战报 → 历史战斗 → Esc 返回；战斗范围切换；成员技能明细；手机统计打开/关闭；设置中切到网页 UI 再切回。
- 长角色名、30 条综合日志和多场历史战报使用真实测试存档验证。
- ESLint、TypeScript 检查通过；Classic 界面逻辑 4 项回归测试通过。

## 透明聊天框与拖动定位

聊天框下移到经验条上方约 10px，左侧距场景边缘 6px；旅行时随旅行条上移。背景使用低不透明度渐变（约 9%—32%），频道栏和选中标签也透明化。文字保留阴影以便在明亮背景上阅读；聊天层级低于场景操作与指挥快捷栏，允许它们覆盖聊天内容。

手机（≤800px）默认仅显示 44px 圆形聊天按钮，展开后保留综合/战报和伤害统计入口，可用关闭按钮收回圆圈。

聊天框和桌面伤害统计的点状柄支持 Pointer Events 拖动，含指针捕获、取消清理及视口/面板尺寸变化后的边界修正。方向键每次微调 10px，双击或 Home 回到默认位置；设置中也有统一重置按钮。位置仅在当前页面会话内保持，刷新恢复默认。

实际验证：桌面两个面板鼠标拖动、双击/键盘复位，拖到右下角限位、1440×900 缩到 1024×768 保持可见，设置统一复位；390×844 手机默认圆圈、展开战报、打开/关闭完整伤害统计、重新折叠。未用真机测试触摸拖动。截图：screenshots/classic-chat-transparent-desktop.png、classic-chat-circle-mobile.png。
