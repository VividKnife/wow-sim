# Classic 地图、旅行和副本场景验收（2026-09-24）

## 本次实现

- Classic 主界面的标题、实景背景与小地图共同读取当前旅行路段。显示层不会提前改变游戏的权威地点、附近服务或任务完成状态；抵达仍由模拟引擎确认。
- 复用客户端快照已有的 `activity.path` 专用投影，因此主界面能显示中间路点，而不只是出发地点。地面改道、折返和飞行沿用已有路线与计时。
- 45 个现有区域都有本地 WebP 游戏截图，30 个现有副本／分区都有副本图片；同一副本的多个入口或分区可共享场景图。没有使用 AI 生图。
- 世界地图展示原版卡利姆多／东部王国大陆纹理，全部 45 个区域标签可点击，也支持键盘操作。点击区域只进入区域地图，点击具体地点才发送旅行指令。入口位于地区选择和“定位玩家”之间。
- 世界地图显示玩家所在地区；“定位玩家”会滚到高亮位置。区域地图定位恢复跟随玩家。手机大陆图保持标签可读并支持左右滑动，初始居中；地图层级切换会把工具栏带回视野。
- Classic 旅行进度位于经验条正上方，保留实际剩余时间、百分比、起终点。物品增益仍保留在页面信息区，未因移动进度条而隐藏。
- 地下城、公会团本、金团使用各自实际地图和路线位置。小地图、底部地图菜单和 M 键打开当前副本地图。
- 副本场景动作替换为停止、跑尸／全团复活、恢复、推进战斗；战斗时主动作显示“战斗详情”。使用现有恢复与推进条件、队长限制和命令，显示操作中／禁用原因，保留公共错误提示与游戏日志。

## 素材与复用

- 图片来源及原图哈希：[scene-backgrounds-manifest.json](../research/import/scene-backgrounds-manifest.json)。主要来自 [Warcraft Wiki](https://warcraft.wiki.gg/wiki/Classic_zones)，每张图片有独立来源页面与原图链接。
- 大陆地图来自固定版本的 [Gethe 原版客户端纹理镜像](https://github.com/Gethe/wow-ui-textures/tree/b852b560442b31579e77ef3967b3c2d594832da8/WorldMap)。导入时校验每块纹理的 Git blob 哈希。
- 复用 `WorldMap`、`DungeonMap`、`GameSelect`、`ActivityProgress`、真实战斗统计和模型动画。第一版 Demo 文件与旧版网页 UI 均保留。
- 导入脚本为 `scripts/import-scene-backgrounds.py` 和 `scripts/import-world-atlas.py`。截图导入缓存原图、记录署名信息；发现限流后停止新网络请求，之后可从缓存继续。修改素材选择后必须重新检查联系表。

## 实际发现并修正的问题

| 问题 | 修正 |
| --- | --- |
| 主界面固定读取权威出发地，没有使用已有旅行分段 | 标题／场景／地图共用路段采样，新增路径投影回归检查 |
| 跨区时小地图仍停留在起始区域 | 跨区路段的后半程交接到目标区域 |
| 世界地图主城与相邻地区标签互相遮挡 | 标签避让、保留真实地理锚点和引线；测试命中区域不重叠 |
| 手机大陆图初始露出过多海面 | 初始水平居中、区域内部滚动；页面本身无横向溢出 |
| 长地图切换后停留在新地图底部 | 切换区域／世界层级时恢复工具栏可见 |
| 明亮场景下地点文字对比不足 | 加强地点文字阴影 |
| 副本恢复时仍提示“等待行动”，停止按钮解释地面旅行 | 使用副本恢复／推进提示与副本停止原因 |
| 自动素材筛选混入插画、首领拼图和出口场景 | 检查完整联系表，更换为实景；死亡矿井改用铁甲湾内部场景 |

## 验证

- 29 项相关测试通过：路线采样、改道／折返／飞行、客户端路径投影、副本与团本命令条件、区域和素材完整性、地图标签碰撞、原有动画／旅行组件。
- 7 项原有副本流程测试通过：服务进入、推进、暂停、恢复、复活、退出和重启持久化。
- Web TypeScript 检查通过。新增场景、地图和 Classic 文件的 ESLint 检查通过。
- 实际浏览器：1440×1000 世界地图、1440×900 副本主界面、390×844 手机主界面／世界地图。
- 完整操作流程：闪金镇 → 世界地图 → 暴风城区域 → 点击暴风城 → 旅行抵达 → 世界地图选择艾尔文 → 点击闪金镇 → 回程抵达。回程 12% 仍显示暴风城截图；80%（剩余 19 秒）已显示艾尔文截图，旅行条继续计时。小地图同步换图，权威抵达日志仍在计时完成后写入。
- 副本实测：死亡矿井中点击小地图，打开真实双层地图和小队当前路点；关闭后回到副本背景。持续推进中的战斗／恢复切换、按钮禁用状态、长遭遇名称和移动端布局均已观察。

## 已知边界与未验证部分

- 现有旅行模型是路点图，没有精确地形边界碰撞。本次按每条路段中点切换附近地点和区域背景，属于展示近似；不会提前解锁飞行点或触发任务抵达。
- 背景按区域／副本选景，不是每个地点、每层楼或每个首领一张图；部分老截图分辨率较低，宽屏会裁切。战斗仍进入原有可交互的 3D 战斗场景。
- 浏览器没有逐一进入全部副本／团本，也没有人为制造团灭验证跑尸；相关命令条件和原有副本恢复／复活流程已通过自动化测试。
- 原有战斗渲染器仍会在战斗切换时报告 React 同步卸载 root 的开发告警，以及 `THREE.Clock` 弃用提示。旅行页面未出现新的运行错误。本次没有改造战斗渲染器，也没有宣称这些告警已修复。
- 未执行生产打包或生产部署。
