# 手机菜单与副本地图优化（2026-09-24）

## 问题与修正

- 390 × 844 下，原副本地图从 y≈437 才出现；弹窗边距、标题图章、嵌套面板和说明挤占首屏。Classic 手机菜单改为全屏，固定 52px 紧凑标题栏，内容独立滚动；统一去掉内层 panel 的重复背景/边框和水平留白，保留内容分隔。
- 手机地图原本强制最小宽度 1200px，只能看到一角。现在默认适配屏宽，从 y≈175 开始，完整显示一个楼层；原图、路线、标记仍为独立交互元素。
- 默认所有楼层纵向铺开，小队可能在第二张地图。现在默认打开小队所在楼层，用 GameSelect 切换，也保留完整副本选项。
- 定位按钮过去只切楼层。现在会将小队带回地图可视区域；放大视图限制高度并允许双向滚动，不会随后台移动强制抢走玩家的滚动位置。
- 缩略图的密集点位不适合精确点击。保留放大，并提供按当前楼层列出的真实首领/区域选择列表。支持键盘和长名称。
- 首领详情原本排在长地图之后。手机选择遭遇后显示独立详情视图，原地图折起；返回恢复同一楼层和缩放。保留敌人、任务、推进限制、行进路线及真实掉落查询。
- 角色页缩小重复标题、法术书多层边框/内边距，首领档案缩小插画与留白。桌面保持原有弹窗尺寸和视觉风格。

## 实际验证

使用正在运行的 Next 应用与真实本地测试存档（死亡矿井，铸造厂西侧），通过浏览器 UI 验证：

1. 打开地图 → 当前船坞楼层 → 切换矿道 → 定位小队返回船坞。
2. 放大 → 小队标记在可视区域 → 点击基尔尼格 → 读取真实掉落及禁用原因 → 返回地图 → 缩小。
3. 区域列表打开 → 键盘 End 滚动长列表 → 选择“艾德温·范克里夫及黑衣卫士” → 详情和装备可见 → 返回原地图。
4. 360 × 740、390 × 844 手机尺寸没有弹窗内容横向溢出；1440 × 900 桌面回归检查通过。
5. 检查角色法术书菜单、任务空状态、始终可用的关闭按钮和返回后的焦点恢复。
6. 当前测试角色已倒下；推进按钮正确禁用并显示复活原因。本轮没有发出推进战斗命令。

验证结果：web TypeScript 检查通过；Classic 操作与副本推进测试 11/11 通过。`dungeon-map.tsx` ESLint 仍有原有 raid loot 两处 explicit-any 报错，未新增 lint 错误。

## 后续：死亡动作重复播放修正

世界角色模型使用固定版本 c3f890f 的查看器。它的 `setAnimation` 第二参数控制混合，不是循环；底层 M2 时间线会自动取模。新增局部适配器使 Death 时间线在该动画实际时长的末帧停止，阻止排队的后继动画；其他动作沿用原始时间线。运动控制器仅在动作改变时调用 setAnimation，因此菜单暂停/恢复不会重播倒地动作。复活到 Stand、再次进入 Death 仍正常切换。两项新回归测试及八项现有模型测试通过。
