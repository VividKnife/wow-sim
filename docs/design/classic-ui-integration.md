# Classic UI 正式接入

采用用户选定的第一版 `/classic-ui.html`：森林场景、头像与血蓝条、金属边框图标栏、左右 HUD、经验条和深绿铜金配色。演示页和 V1 归档保留。V2 未替换它。

## 玩家入口与状态边界

- 正式入口仍是登录后的 `/?saveId=…`，默认 Classic。
- Classic 图标栏下方的「切换为网页 UI」和旧网页顶部的「切换为经典 UI」可互相切换。
- 偏好存于 `wow-sim:interface-style`，跟随当前浏览器，不写入角色存档。刷新保留；存储不可用时当前会话仍可切换。
- `Game` 始终持有同一个游戏状态、角色、命令队列与 LocalSimulationClient。界面切换仅改变显示方式，不重新创建游戏、不调用重置命令。
- 原来的完整网页 UI 继续保留。切换时尽量映射到对应功能页。

## 核心操作循环和功能映射

核心循环：查看自身状态与任务 → 与人物交谈接取任务 → 地图选择目的地 → 旅行/骑乘 → 选择野外目标或副本路线 → 自动战斗与补给 → 拾取、装备或交任务 → 再次出发。

| 入口 | 玩家决定与必要信息 | 主要操作与真实结果 |
| --- | --- | --- |
| 主场景 | 当前地点、生命、职业资源、活动、经验、队伍、任务追踪 | 地图移动、按已拥有的坐骑召唤/下马、停止活动、进入野外活动 |
| 附近人物 | 当地可用 NPC、任务与服务 | 原 `LocalNpcs` 对话、接取/交付/选奖、商人和训练师等服务 |
| 任务 | 当前目标计数、完成状态、交付位置 | 原任务日志和导航命令；前往任务或交付区域 |
| 角色/背包 | 装备、物品容量、技能、天赋、策略、坐骑与生活职业 | 原 `Character` 中实际装备、使用、配置、银行与拍卖行入口 |
| 地图 | 区域、真实节点、路线时间和服务解锁情况 | 原 `WorldMap`；采用统一自定义区域选择控件 |
| 队伍 | 成员、等级、职业与可用职责 | 原队友招募、配置与副本组队；未解锁时显示等级要求 |
| 地下城/团本 | 当前队伍和准备条件、路线、推进状态 | 原副本、普通团本及金团页面与命令 |
| PvP | 原系统的战场/竞技场状态和准备条件 | 复用原 PvP 页面；不伪造排队或奖励 |
| 战报与活动 | 实际伤害、DPS、技能明细、掉落和旅途记录 | 下滚查看或打开原完整战报；保留统计范围选择 |
| 角色与后台 | 当前账号角色和后台活动 | 原角色切换、生产采集与召回控制 |

野外/副本战斗替换主场景。完整战斗详情仍可打开。桌面显示真实队伍/团队与 DPS；窄屏下移到滚动详情区。未组队显示本人，尚未战斗显示空状态，不填充演示队员或假数值。

## 复用与样式

外壳位于 `app/classic-game.tsx` / `.css`。`World` 新增附近人物、任务、地图、活动四个显示范围，内部操作复用原组件。图标、角色模型、装备与骑乘动画沿用项目资源。只有艾尔文/北郡使用 V1 森林图片，其他地区沿用已有区域背景；没有为未制作的地区伪造专属插画。

任务、物品和服务继续使用既有组件的选中、禁用、忙碌、错误和奖励状态。Classic 统一弹窗边框与底色，保留嵌套对话框和 GameSelect。快捷键 N/L/C/B/I/H/P/M 在输入框及弹窗内不触发。

## 实测与修正（2026-09-24）

测试在独立本地 PostgreSQL 数据库和专用 QA 账号内进行，未使用既有玩家存档。

1. 一名长名称 1 级法师接取「休息和放松」，使用任务导航去闪金镇；旅行中切成网页模式并刷新，再切回 Classic。地点、角色、任务和旅行继续保持。
2. 抵达后与法雷交谈；未选择奖励时「完成任务」禁用，选择泉水后成功提交。经验从 0 增至 100，背包显示泉水共 7 瓶，任务不再列为进行中。
3. 20 级正式创建角色召唤旅行棕马并从暴风城骑往闪金镇；途中下马按钮按真实规则禁用。
4. 从野外活动开始狩猎森林蜘蛛，主场景显示实时 3D 战斗。战利品弹窗、自动拾取、战后 DPS（102 有效伤害 / 约 15 DPS 的一场）均来自实际战斗。
5. 战斗中 Classic → 网页 → Classic，角色、消耗、自动狩猎和掉落继续；随后通过停止按钮停止狩猎。
6. 1440×900、390×844、320×740 检查；390/320 页面宽度均等于视口宽度，无页面横向溢出。手机背包长内容在窗口内滚动，地图保留自身横向浏览区域。
7. 嵌套 NPC 对话、奖励选择、地图自定义区域下拉、背包、刷新后的风格记忆已验证。
8. 在实际队伍窗口招募战士、牧师、猎人、潜行者，完成猎人自动补齐弹药提示。主 HUD 正确显示五名真实成员及对应生命数值。焦点与模型就绪修正后的复测未产生新的异常。

发现并修正：

- 长名称挤占血蓝条/队伍信息：主框与窄队伍栏截断，完整姓名保留在角色窗口/悬停提示。
- 新外壳覆盖旧弹窗/下拉层：统一 Classic 内外弹窗和下拉层级。
- 快速关闭再打开窗口时焦点竞争及页面跳动：焦点恢复延后到下一帧，已有打开窗口时不抢焦点，并禁止自动滚动。
- 旅途记录把绝对时间当作分钟累计显示：改为本地时分。
- 死亡、地面旅行、已点燃火炮等不能停止的活动：主按钮按引擎规则禁用；地下城、普通团本、金团使用各自暂停命令。
- 坐骑模型加载期间接到动画指令可能触发渲染器异常：动画指令先保留，模型就绪后再应用，不改变已有动画及镜头算法。
- 移除从演示外壳复制来的未使用样式，避免继续维护虚构的演示功能。
