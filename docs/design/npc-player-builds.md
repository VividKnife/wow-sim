# NPC 玩家等级、天赋与策略方案

2026-10-02 更新。用于社交与地下城查找器中的持久 NPC 玩家、五人副本和金团；玩家手动策略不受影响。

## 生成、匹配与自主成长

正式入口为「社交与地下城查找器」。NPC 为服务器公共角色，查找器使用队长 −1～+3 等级范围；10—59 级按需求再分布，60 级永久保留装备与资产。实际经验成长、专业收入、五人本每日/每周模拟与团本 CD 补团规则见 [公共池与两阶段成长](npc-player-public-pool.md)。

## 生活技能与经济

每位 NPC 固定拥有一组两项主要专业（采药/炼金、采矿/锻造、剥皮/制皮、裁缝/附魔、采矿/工程），以及钓鱼、烹饪、急救。目标熟练度为等级 ×5，最高 300；实际熟练度和上限受对应专业的训练等级与技能门槛限制。生成、后台升级和战斗档案同步时更新，不产生额外主要专业。

后台专业收入为抽象的净劳动收入，已扣除材料、训练、旅行和交易成本，不会再凭空发一份材料。每小时铜币收入为：`60000 × (主要专业熟练度之和 / 300 × 0.5 + 副职业熟练度之和 / 300 × 0.1) × 技术倍率`，优秀倍率为 2，其他为 1。五项专业均满时为普通 7.8 金/小时、优秀 15.6 金/小时；这是专业工作时间的时薪；当前仅分配 25% 在线活动预算，低级随熟练度降低。

豪爽老板与上头土豪在原初始资金外增加 `1000 × 等级 / 60` 金，并每小时获得 `150 × (等级 / 60)²` 金额外收入；与专业收入独立。每次后台结算最多购买一件现有拍卖行在售的蓝色/紫色装绑，只购买满足装备条件且提高职责评分的商品，保留 `20 × 等级 / 60` 金旅行资金。复用市场报价、阶段限制和个人库存扣减；实际扣款、生成独立物品 ID 并装备绑定，不把世界掉落表直接变成商店。

专业熟练度、市场库存、累计专业收入/额外收入/购物支出与角色档案持久化；金币和购买装备仍进入独立钱包与物品资产表。

上述速度与经济参数是当前游戏平衡值，可独立调整；尚未以真人实测每小时产出做校准。

## 方案维度

九职业、18 种职责组合 × 10/20/30/40/50/60 级 × 新手/普通/优秀，共 324 个基础方案。性格在此基础上修正决策。等级档向下取整：例如 37 级使用 30 级战术，法术等级仍更新到实际 37 级可学的最高等级。1—9 级沿用入门战术并过滤未学技能；每次升级分配实际可用的天赋点。

| 职业 | 职责及天赋方向 | 核心战术 |
| --- | --- | --- |
| 战士 | 防护坦克、狂怒双持输出 | 坦克维护破甲、复仇、盾猛；输出使用嗜血、斩杀，普通/优秀加入旋风斩和死亡之愿。20 级前输出使用双手武器。 |
| 圣骑士 | 防护、神圣、惩戒 | 坦克圣盾与正义之怒；治疗以圣光术/闪现分工；惩戒命令圣印、审判和愤怒之锤，互斥光环不轮流补。 |
| 猎人 | 新手/普通兽王，优秀射击 | 兽王使用狂野怒火；射击使用瞄准射击、强击光环。优秀玩家单体也用多重射击；瞄准与奥术射击不争用共享冷却。 |
| 潜行者 | 战斗输出 | 邪恶攻击、切割、剔骨；普通/优秀加入剑刃乱舞、冲动。不同时投资互斥武器专精，便于持久 NPC 正常换装。 |
| 牧师 | 神圣治疗、暗影输出 | 治疗随等级从次级治疗术转治疗术、强效治疗术；暗影维持形态、痛、震爆、鞭笞。 |
| 萨满 | 恢复、增强、元素 | 治疗波/次级治疗波/治疗链；增强风怒与风暴打击；元素闪电箭、条件群体闪电链。每个元素保留一种常驻图腾。 |
| 法师 | 冰霜输出 | 寒冰箭、低蓝唤醒；普通/优秀加入暴风雪、打断和解诅咒；高等级使用寒冰屏障、寒冰护体保命。 |
| 术士 | 痛苦，优秀 30 痛苦/21 毁灭 | 持续伤害与暗影箭；普通玩家使用黑暗契约，优秀玩家取得毁灭。空蓝宠物不会使黑暗契约卡住循环。 |
| 德鲁伊 | 熊坦、猫、平衡、恢复 | 熊坦维护仇恨，猫撕扯/撕咬并按站位使用撕碎；平衡枭兽/星火；恢复治疗之触/持续治疗/迅捷治愈。 |

这些是当前执行器支持的 PvE 方案，不是全部天赋流派，也不声称为原版毕业最优解。不得通过职业伤害倍率补偿策略问题。

## 每十级的演进

| 等级档 | 安排原则 |
| --- | --- |
| 10 | 简单主攻、基本增益、自保；按职责开始定向加点。 |
| 20 | 加入已解锁的形态、终结技、第一批天赋主动技能和小规模群攻。 |
| 30 | 加入资源管理、打断与团队支援；输出开始安排可用的爆发技能。 |
| 40 | 使用本方案已点出的核心天赋技能：嗜血、盾猛、狂野怒火、风暴打击、暗影形态、枭兽等。未达到前置条件时不会授予技能。 |
| 50 | 主树成熟后扩展副树；更新高级驱散、斩杀、额外资源与爆发管理。 |
| 60 | 完整 51 点天赋与最高可学技能等级；延续已有战术，不为了等级档强行插入无收益技能。 |

天赋采用显式优先项及点数上限，逐点检查数据中的层数与前置天赋。新手适量优先生存，普通玩家围绕稳定循环，优秀玩家可采用更依赖资源管理的构筑。某些职责共享合理的天赋核心，熟练度差别主要体现在施法决策，而非故意点错天赋。

## 熟练度与性格

| 维度 | 行为 |
| --- | --- |
| 新手 | 保留核心输出/治疗/坦克技能，少用额外爆发和复杂支援，更早自保、开怪等待更久。金团仍使用已有的新手犹豫和躲火模型。 |
| 普通玩家 | 核心循环完整，加入常规打断、驱散、爆发、条件群攻。 |
| 优秀玩家 | 在普通方案基础上更积极使用高收益群攻、资源技能及支援，缩短开怪等待；始终保护控场、等待坦克建立仇恨。 |
| 稳健派 | 更早自保、更长开怪等待，装备比较略提高生命权重。 |
| 热心派 | 更早响应队友受伤，更提前补团队增益。 |
| 装备控 | 配装略偏重输出收益，保留基础保命与控场保护。 |
| 排骨/理性/收藏/豪爽/上头 | 独立的消费性格。日常排骨默认不自动喝背包药水；上头玩家更早喝药。金团自费药水仍结合消费性格、熟练度与已公告奖金决定。 |

熟练度、社交性格和消费性格分别保存，不再让某个职业因为居民序号恰好总是同一种社交性格。成功参与一次有击杀的金团后，新手晋升普通；累计三次晋升优秀，同步重配天赋与策略。

## 装备与持久化

- 初始选装、日常换装、金团竞价评估共用角色完整属性评分，计入法伤、对应学派、治疗、命中、暴击、攻强和武器伤害。评分是 NPC 的选择启发式，不是精确 DPS 模拟器；未建模的主动/触发效果仅有少量物品等级估值。
- 熊/猫不把武器面板 DPS 当作形态伤害收益；双持、双手、盾牌与构筑匹配。
- 等级提升、熟练度晋升及五人本入场更新技能、天赋、策略、自动增益、药水偏好与方案标识，保留装备、钱包、身份和性格。
- 不增加旧存档迁移。完整初始配装与新居民性格分布通过新建世界获得；已有居民在正常升级、入场或晋升时使用当前训练流程。
- 金团玩家档案显示等级/熟练度方案、社交性格、技能优先级和实际天赋，便于检查。

## 验证

`packages/game-domain/test/npc-builds.test.ts` 检查全部 324 个基础方案和所有 1—60 级点数预算、前置天赋、技能等级、互斥增益、性格差异、真实战斗核心技能、持续状态不重复施放、成长与晋升后的持久化，以及配装评分。

运行：`node --test packages/game-domain/test/npc-builds.test.ts packages/game-domain/test/npc-world.test.ts`。

原有 Classic 公式近似、首领的 25 人改编数值和未逐项校准的宠物机制仍存在；本次解决 NPC 构筑与施法行为，不构成“完整原版职业 DPS 校准”的证明。

## 副本补给与团长补增益指令

- 生命、法力药水统一使用 `professions-reference.json` 的真实物品恢复范围，以及 `item_template` 的使用等级和共享冷却。60 级金团使用特效治疗药水（13446，1050–1750 生命）或特效法力药水（13444，1350–2250 法力），两者共享 120 秒冷却；进入下一场战斗或休整不会清除此冷却。
- 金团 NPC 从自身钱包按游戏市场价格购买，记入消耗支出。移除原来每 45 秒同时恢复 30% 血蓝的虚构药水。原来的四分钟全属性 +12 替换为坚韧药剂（3825），从物品法术读取 +120 生命、一小时持续时间。经济价格是本项目市场定价。
- 五人副本休整区和金团指挥台提供“全团补 Buff”，命令 `partyBuffs` 仅在副本内非战斗、空闲时可用，停止自动推进。可随时停止；执行时禁止直接发起下一场战斗。队列、进度、消耗和冷却均随实例存档。
- 按已学技能和职责分配增益：全员获得奥术智慧、神圣之灵、韧、暗影防护、野性印记；坦克获得荆棘。按法术等级选择施法者，同等级时分担工作；未学会或缺少对应职业时不创建增益。
- 每位圣骑士对每名目标只负责一种祝福：优先王者，再按职责安排智慧或力量，其次非坦克拯救／坦克庇护，最后光明。王者、神圣之灵等仍受真实天赋与已学技能限制。先完成长效增益，再安排祝福，避免提前过期。战斗中的光环、战吼、图腾继续由职业战斗策略处理，不作为可永久覆盖全团的长效增益。
- 使用实际法力消耗与公共冷却。NPC 法力不足时用自身钱包购买对应等级饮水；买不起时等待自然恢复，队长按现有恢复设置使用补给。已学群体技能时优先按五人小队施放；强效祝福按同职业施放。每次施法扣一次真实材料；NPC 自费补足，玩家使用自己背包，缺料或未学会时改用单体。不同职责需要不同祝福时保留单体分配。
- 生还成员开战前保留尚未过期的增益及回蓝周期效果；倒下成员在休整复活时清除增益，需要重新下令补充。

25 名玩家需要五次祷言覆盖五个小队，并非一次加满全团。每次群体施法只扣一次法力、材料和公共冷却，产生一条带实际 spellId 和 targetIds 的施法成功日志；单体与群体版本不叠加属性。小队顺序与团队框架及战斗分组一致。

补增益面板使用全局效果音设置，默认遵循玩家已有静音偏好。通过游戏统一的“音效”开关与音量控制，不设置独立增益音效按钮；开启音效后，只播放新发生的施法成功事件，不重播挂载前、离线、隐藏标签页或超过 1.5 秒的历史事件。群体技能只响一次，不按人数重复。音频来自 Classic 技能页面对应的 BurningSpirit、HolyProtection、SealofMight、Thorns 原始资源，未合成或变调；来源、哈希、Vanilla 路径和解码结果见 `docs/research/import/buff-sounds/`。音频是 Classic 服务提供的 OGG 编码，不宣称与原始客户端字节完全相同。

### 团队增益检查面板

副本内非战斗时提供逐成员检查：默认查看仍缺增益的成员，可展开全部成员，按小队标识排列。显示增益名称、施法负责人，以及待补、回蓝、公共冷却、施法、缺材料转单体、无人掌握、等待复活等原因。已覆盖数量按“成员 × 增益”统计，剩余施法次数按真实队列统计，群体祷言一次可补多项。阵容缺少的技能单独汇总，不会误报正在排队，也不会假报全团齐全。

检查视图复用实际分配与覆盖规则，只读计算，不扣材料或改变随机数。下令当刻初始化剩余次数；检查结果和已完成次数通过快照传到界面，避免首帧显示省略号。停止后仍可检查，增益过期会重新显示缺失。

金团成员锁定名单时默认自费备好十轮全团补 Buff 的材料，不受熟练度或节俭性格影响；每次下令补 Buff 前补足库存。按已学技能计算：每个小队类增益预留 50 次，强效祝福共用 90 个王者印记，不按祝福种类重复采购；另为已学复生、神圣干涉准备 10 个对应材料。实际材料堆叠存入 NPC 背包，施法扣库存，剩余库存与钱包随居民保存，费用计入消耗支出。仅采购已入团成员；金币或背包空间不足时明确记录缺额，不生成免费材料或透支钱包。
