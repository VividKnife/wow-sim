# 沉浸式小队指挥：职业快捷栏与队长命令

状态：Classic 首版已接入。战斗覆盖地区行走画面，副本快捷操作切换为职业／队长快捷栏，支持独立队员与目标选择、实时指令、暂停、临时单体／范围输出、维持控场与单次技能队列。以下仍保留后续设计：指定治疗与驱散、战外制造、可保存槽位、地面定点、头像任务角标及控制剩余时间。未实现能力不显示按钮。

## 核心体验

玩家指挥五人小队，自动战斗继续承担常规循环。随时选中一名队员，通过其实际已学能力干预关键时刻；也可以向全队发布命令。实时下令不自动暂停。战前勾选指挥模式只决定新遭遇是否先暂停，战中可主动暂停、布置或继续。

操作遵循「队员 → 动作 → 目标」。也支持先选目标再点技能，减少熟练玩家的点击次数。角色选择与敌方目标选择分离：点击敌人不会把法师的技能栏换走。

## 战场布局

- 沿用经典 UI 的暗色皮革、金属边框、职业色和真实技能图标，不增加独立战术窗口。
- 左侧现有队伍框架直接选择受令角色，高亮边框；头像角标表示持续任务、等待或失效。
- 顶部仅保留紧凑的目标框：敌人名称、生命、施法、控制剩余时间和骷髅／月亮等标记。标记展开为一小排图标。
- 底部居中是选中角色的 6–8 格职业快捷栏，角色头像、资源及当前任务构成同一条。更多能力折叠，槽位按角色记忆；新学技能不挤走旧热键。
- 队长栏是技能栏旁的独立小组：集火、单体、范围、停火／恢复、取消战术；暂停键独立，避免与停火混淆。
- 中央视野持续留给战斗。只有选择地面技能时显示范围圈，等待选目标时显示一行提示，不显示表单、下拉框或长说明。
- 手机：现有队伍框变横排头像，选中角色栏最多两行；队长栏用一个常驻旗帜入口展开，选敌后自动收起。技能可点，重要信息不依赖悬停。

## 三类指令

1. **持续打法**：单体输出、范围输出、风筝、保护某队友。按钮点亮，维持到替换／取消／遭遇结束。
2. **单次技能**：打断、硬控、嘲讽、驱散、防御、指定治疗。成功执行后回到原来的持续打法；资源或冷却不足可排队，但只保留一条待执行技能，显示原因并可取消。
3. **维持控场**：变羊、闷棍、冰冻陷阱等。第一次真实施放成功后保留控制任务，按技能与战斗条件补控；目标头像显示锁定标志。点亮的控场按钮可取消保留。闷棍不能在已交战后自动补；陷阱不能绕过布置条件。

角色的持续打法与单次技能分别存储。一次打断不会丢掉风筝职责。一个敌人只保留一个主要软控任务；替换时清楚显示新的负责者。默认禁止范围输出打醒保留目标，释放集火到该目标时才明确解除保留。

## 队长栏

| 操作 | 行为 |
| --- | --- |
| 集火 | 对当前敌人标骷髅，输出与宠物优先攻击；坦克仍处理必要的接怪，治疗继续救人 |
| 单体 | 全队输出避免伤害型群攻，围绕集火目标；治疗和必要的群体控制不受此限制 |
| 范围 | 启用队员实际已学范围能力；仍受控场保护、射程、资源与仇恨约束；没有范围技能的角色继续单体 |
| 停火 | 停止主动伤害与新的伤害读条，宠物跟随；治疗、防御与已分配控制继续。不会清除在途弹道和已有持续伤害 |
| 恢复自动 | 取消临时打法与排队技能，回到已保存策略；与单独撤销某个控制任务分开 |
| 战术暂停 | 冻结模拟时间，便于布置；不改变停火状态、不恢复资源与冷却 |

集火不等于「所有角色无视职责攻击」。范围命令也不允许凭空制造群攻技能。

## 职业快捷栏候选

以下是候选能力，实际只显示已学最高等级、天赋及当前形态支持的能力。长期不可用的能力不占槽，暂时不可用的能力变暗并注明原因。

| 职业 | 常用战术 | 条件技能与生活能力 |
| --- | --- | --- |
| 战士 | 接住目标、保护队友、单体／群体拉怪 | 嘲讽、盾击／拳击、防御技能、姿态 |
| 圣骑士 | 保护、指定治疗、单体／奉献 | 制裁之锤、净化、保护祝福、圣疗、祝福 |
| 猎人 | 单体、风筝、群射 | 冰冻陷阱、震荡射击、宠物攻击／跟随、假死 |
| 潜行者 | 单体、打断、控制 | 闷棍、脚踢、凿击／肾击、闪避、潜行 |
| 牧师 | 指定治疗、保护、驱散 | 真言术：盾、快速治疗、束缚亡灵、渐隐、恐惧、耐力 |
| 萨满 | 治疗、打断、单体／链式输出 | 地震术、净化术、地缚／战栗／治疗图腾 |
| 法师 | 单体、范围、风筝 | 变羊、反制、新星、解除诅咒、造食／造水 |
| 术士 | 单体／范围、控制 | 恐惧、放逐、死亡缠绕、宠物指令、制造治疗石 |
| 德鲁伊 | 治疗、输出／坦克形态 | 休眠、缠绕、驱散、熊形态嘲讽／重击、复生 |

生活与准备能力在非战斗时优先出现，例如制造食物、水、治疗石、补增益。战斗中不突然重排槽位，相关技能变暗并给出游戏规则规定的不可用原因。制作产物必须进入实际背包并遵循容量、材料、施法和资源规则；队友制作需要对应的成员施法执行链。

## 选择、瞄准与反馈

- 点左侧队员或场景中的友方单位切换施法者；点敌人只改变目标，保持施法者。
- 点目标型技能后进入瞄准状态：鼠标指示技能，合法目标高亮，非法目标有禁止反馈。点合法目标提交，右键或 Esc 取消瞄准。
- 已选合法目标时，快捷键直接下令；不合法时进入选目标。治疗、驱散选友方，嘲讽、打断选敌方，自身技能立即执行。
- 地面范围技能支持选落点，并显示范围；无地面定位实现时只能提供「范围输出」战术，不能伪装成可定点的暴风雪。
- 读条使用已有施法条；技能格显示资源不足、冷却遮罩／秒数、排队角标；头像显示「维持变羊」「等待读条」「正在风筝」。
- 敌人死亡、队员死亡、目标免疫等使任务失效时，清理对应任务并短暂提示；不把失效命令永久留在队列里。
- 精确点名打断需要足够响应：若正在读非关键伤害法术，可为可执行打断取消自己的伤害读条；不得无条件取消治疗或持续控场。
- F1–F5 选队员；1–8 执行职业槽；Shift+数字执行队长槽；Tab 切敌。输入框、弹窗和文本编辑期间禁用。Esc 首先取消瞄准，再关闭轻量展开，不隐式暂停战斗。

## 自动战斗优先级

目标合法性和硬性技能规则 → 玩家单次指令 → 维持控场／风筝职责 → 生存与治疗职责 → 输出打法 → 原有策略。危险治疗可作为明确的紧急例外；界面必须说明被延后原因。

全队命令决定默认打法，角色命令覆盖本角色。明确的单体／范围模式不能永久改写玩家保存的策略；恢复自动后恢复原配置。战后清空本场目标与队列，保留个人栏位与战前指挥偏好。

## 实施拆分

第一步以已有集火、控制、标记、风筝、停火、暂停能力完成战场内快捷栏替换，同时支持角色选择与目标选择分离。第二步增加持续输出模式和实际单次技能队列，覆盖坦克／治疗职责。第三步接入战外制造与增益、可保存栏位和地面定点；每一步只出现真正可执行的按钮。

## 首版实际交互

Classic 战斗直接铺满地区场景，不自动打开独立战斗弹窗；结束后恢复原副本快捷操作。桌面用左侧队员框切换角色，窄屏在技能栏上方显示五个队员入口。队长栏在窄屏通过旗帜展开。F1–F5 选人、1–8 职业快捷键、Shift+1–5 队长快捷键；按钮焦点下保留正常 Tab 导航。临时打法不改写角色保存的战斗策略。

验收重点：不打开战斗详情弹窗即可实时下令；连续切换敌人不丢失施法者；范围模式不会破坏软控；一次打断不取消风筝；暂停与停火相互独立；手机选目标可完成；刷新后的任务和暂停一致。
