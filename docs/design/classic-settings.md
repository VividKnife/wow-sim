# Classic 设置菜单

团本后增加齿轮图标。主页 Esc 打开设置，弹窗内 Esc 关闭当前弹窗；打开其他模态窗口时不会在底层再打开设置。

设置集中提供音乐、音效开关及各自音量，自动拾取、脱离卡死、角色选择、退出游戏（调用现有退出账号流程）。Classic 原有页顶账号入口、底部音乐/脱离卡死入口、战斗中的音效控件、无掉落时的自动拾取浮动按钮收拢至设置；实际战利品入口保留。网页版原有入口保留，同步使用统一声音偏好。

音乐控制器始终挂载，关闭设置不会停止播放。音乐和音效偏好保存在浏览器并即时通知当前播放器；音效同时控制战斗与任务提示音。自动拾取通过现有角色 settings 指令保存，包含操作中、成功及失败反馈。脱离卡死保留既有确认说明。

战利品弹框保留可直接切换的「自动拾取」复选框，与设置菜单共用角色设置；操作期间禁用。

验证：

- 独立测试角色自动拾取开/关保存成功，刷新后保留；音乐开关/音量刷新后保留；测试结束恢复原偏好。
- 当前游戏角色因其他页面持有运行权，保存失败时保持服务器原值并显示失败提示，未绕过页面保护。

- 声音偏好、音乐播放器、战斗音效和任务音效共 16 项测试通过；web TypeScript 与本次设置/音频/Classic 组件的 ESLint 检查通过。

## 特效设置

新增“画面与特效 / 简化特效”，复用现有 lowEffects 渲染路径：降低粒子、同屏弹道与命中特效数量，关闭动态阴影及后期效果，降低像素比。普通战斗与竞技场通过共享订阅实时读取同一偏好，不再在每次挂载时覆盖玩家选择。无已保存选择时沿用手机默认简化的规则。Classic 战斗工具栏旧开关收拢至设置。

已验证开关、关闭后重开保持、手机无横向溢出和返回路径；偏好持久化/订阅回归测试通过。手机截图：screenshots/settings-effects-mobile.png。本次未重新触发真实战斗或测量帧率。

## 自动拾取过滤

设置「游戏」中新增「跳过灰色物品」，默认关闭；需要先开启自动拾取。过滤依据物品实际品质（Quality 0），随角色设置保存。旧网页战利品窗口也提供同一选项。

灰色物品保留在待拾取列表，仍可手动领取，不阻塞自动狩猎、副本和团本推进。仅剩被过滤物品时不会自动弹出战利品窗口；正常物品放不进背包时仍保留并阻止推进。关闭过滤后，自动拾取会重新收取保留的灰色物品。

验证：拾取与副本进度测试共 20 项通过，包含过滤、手动领取、关闭过滤、满包和连续战斗。实际页面已显示设置入口及保存反馈；发现开发服务器未加载新规则后已重启。随后浏览器连接不可用，刷新持久化与本次手机截图尚未完成验证。
